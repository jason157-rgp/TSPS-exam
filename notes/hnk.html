01顏面表情肌的深層例外 —— LAMB 口訣§

HNK · HN1 顏面神經麻痺/facial reanimation
只有最深層的三條肌肉反而「從淺面」受支配：Levator anguli oris、Mentalis、Buccinator。

顏面表情肌絕大多數由顏面神經從深面進入支配。只有最深層的三條肌肉，它們反而「從淺面」受支配 —— 這就是 GS 的 LAMB 口訣：

  • Levator anguli oris（提口角肌）
  • Mentalis（頦肌）
  • Buccinator（頰肌）

02Cordeiro 上頜切除重建記憶矩陣§

HNK · HN11 midface/上頜重建(Cordeiro)
用「幾面牆 + 眼球在不在 + 硬顎在不在」三個開關，直接推出皮瓣選擇。

為了在考場上能用反射神經秒殺這類題目與後續的皮瓣選擇題，把這張矩陣印在腦海裡：

分類 (Type)核心定義與切除範圍關鍵保留結構（考場防雷）重建戰術思維（N3-9 核心）
Type I
(Limited)		1 ~ 2 面牆。眼球保留、眼底保留、硬顎保留。缺損體積小但表面積大。首選橈前臂皮瓣（radial forearm）或 ALT。
Type II
(Subtotal)		下方 5 面牆（含硬顎破洞）。眼眶底（orbital floor）必須完整。重點在重建硬顎。常選用骨皮瓣（fibula）或軟組織皮瓣（ALT／rectus）搭配閉塞器。
Type IIIA
(Total)		全部 6 面牆（含硬顎與眼底）。眼球保留（orbital contents preserved）。必須同時重建硬顎與眼眶底支撐。常以骨移植撐起眼眶底，再用腹直肌皮瓣（RAM）填補與鋪底；或使用雙管腓骨皮瓣（double-barreled fibula）。
Type IIIB
(Total + Exenteration)		全部 6 面牆 ＋ 眼窩剜除。無（眼球與硬顎皆無）。巨大的立體缺損。使用多皮島的腹直肌皮瓣（RAM）同時重建硬顎與填補眼眶死腔。
Type IV
(Orbitomaxillary)		上方 5 面牆 ＋ 眼窩剜除。⭐ 硬顎保留（palate is intact）！不需重建硬顎。主力為填補眼窩與顱底死腔，首選 ALT 或 RAM 皮瓣。
← 表格可左右滑動 →
🚨 考場地雷最容易被混淆的是 Type II vs Type IV：兩者都是「5 面牆」，差別在 Type II 破了硬顎、Type IV 硬顎完整。硬顎在不在，直接決定要不要做閉塞器／骨重建。

⭐ 記憶錨點整張表只要記三條線：① 順位 ALT → RFF → jejunum；② jejunum 唯一的優點是 primary healing 最好，其餘幾乎全是 ⚠（donor morbidity 高、恢復慢、stricture 高、TEP voice 差、不能做部分缺損）；③ 禁忌各自對應自己的解剖（ALT 怕胖、jejunum 怕開過腹、RFF 怕手臂太細）。
🚨 考場地雷⚠ TEP voice 那一列是最愛考的單格：jejunum 差（分泌黏液、蠕動干擾氣流），ALT 與 RFF 都 Good。看到題目問「發聲重建效果最差的皮瓣」直接選 jejunum。
