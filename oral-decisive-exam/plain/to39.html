Blepharophimosis-Ptosis-Epicanthus inversus Syndrome（BPES）

眼整形 · 🟡

一句話定位：四大特徵 ＋ 一個基因 ＋ 兩型 ＋ 分期治療——是一題結構極清楚、背了就能全拿的題目。

核心模範答案

「報告老師，BPES 是 blepharophimosis-ptosis-epicanthus inversus syndrome，體染色體顯性遺傳，致病基因是 FOXL2。

【四大特徵】

  • ① ⭐ Blepharophimosis——瞼裂在水平與垂直方向都變短（正常成人水平瞼裂約 28–30 mm，此症明顯縮短）。
  • ② ⭐ Ptosis——而且 levator function 通常很差（poor，≤ 4 mm）。
  • ③ ⭐ Epicanthus inversus——內眥贅皮的皺褶由「下往上」走，與一般東方人的 epicanthus（由上往下）方向相反，這是本症的命名來源。
  • ④ ⭐ Telecanthus——內眥間距（intercanthal distance）過寬，但兩眼眶的骨性距離正常（⚠ 這是 telecanthus，不是 hypertelorism）。

常合併：下眼瞼外翻或 lateral ectropion、鼻樑扁平、低位耳、外眥往下移位。

【⭐ 兩型——這是最常被追問的一點】

  • Type I：合併 premature ovarian failure（早發性卵巢衰竭）→ 女性不孕。
  • Type II：不合併，僅有眼部表現。

⭐ 臨床意義：診斷 BPES 的女嬰，必須轉介遺傳與內分泌科追蹤卵巢功能，並做家族諮詢——這一句是本題的加分點。

【⭐ 治療——分期進行，順序不能顛倒】 第一期（一般 3–5 歲）：內眥成形術——矯正 epicanthus inversus 與 telecanthus。術式：discrepant Z-epicanthoplasty、Mustardé 四瓣法（double-opposing Z-plasty）、Y-V advancement；telecanthus 明顯者加做 transnasal wiring 或 medial canthal tendon plication。 第二期（間隔 3–6 個月後）：ptosis correction——因為 levator function 差，多數需要 frontalis sling（自體 fascia lata 為 gold standard；年幼者可先用 silicone rod）。 ⭐ 為什麼是這個順序：先把內眥拉正、把瞼裂的水平長度做出來，之後做 ptosis 矯正時的高度與弧度才有正確的參考基準；順序顛倒會做出不對稱的結果。 ⚠ 例外：如果 ptosis 已經嚴重到遮蔽視軸、有 deprivation amblyopia 的風險，就必須提前處理 ptosis，並全程眼科追蹤視力與屈光。」

追問樹

  • 「Epicanthus inversus 和一般東方人的 epicanthal fold 差在哪？」 → ⭐ 方向相反。一般東方人的 epicanthus（tarsalis／palpebralis）是皺褶由上眼瞼往下延伸；epicanthus inversus 是由下眼瞼往上走，蓋住內眥——這是 BPES 的診斷性特徵。
  • 「Telecanthus 和 hypertelorism 怎麼分？」 → ⭐ Telecanthus ＝ 內眥間距過寬但眶間距（interorbital distance）正常，是軟組織／內眥韌帶的問題；hypertelorism ＝ 骨性眶距真的變寬。⭐ 鑑別方法是量 intercanthal distance（正常 30–34 mm）與 interpupillary distance，並用影像確認眶壁位置。（⚠ 這一組對比在 NOE fracture 題也會考。）
  • 「為什麼 BPES 的 ptosis 要用 sling？」 → 因為它的 levator function 通常很差（poor），levator resection 再怎麼切也拉不動——必須換動力來源，借額肌。
  • 「小孩幾歲開？」 → ⭐ 沒有遮到視軸 → 3–5 歲（可配合檢查、可取足夠 fascia lata、入學前完成）；⭐ 遮到視軸 → 提早，以避免 deprivation amblyopia。
