Jersey finger 與 FDP 撕脫（Jersey finger; FDP avulsion; Leddy–Packer classification）

手外科與周邊神經 · 🔴

一句話定位：簡守信 104–111 每年必出的影片題——分型的價值在於它直接決定「你有幾天可以開刀」。

核心模範答案

「報告老師，影片顯示病人在固定 PIP joint 的情況下無法主動屈曲 DIP joint，代表 FDP 的連續性中斷，診斷是 FDP disruption。 若病史是橄欖球／柔道抓對方球衣時被強力拉開，即為典型的 Jersey finger（closed FDP avulsion），⭐ 好發於 ring finger——因為環指的 FDP 止點抗拉強度較弱，而且伸指時它最突出。

【理學檢查】 固定 PIP 測 DIP 主動屈曲 ＝ 測 FDP；固定其餘手指的 DIP 於伸直位測 PIP 屈曲 ＝ 測 FDS。掌側可能沿腱鞘有壓痛，可依壓痛最遠端推測肌腱回縮的位置。

【⭐ 分型：Leddy–Packer classification——它決定手術的時間窗】

  • Type I：肌腱回縮到手掌（vincula 斷裂、血供中斷）→ ⭐ 時間窗兩版並列：一版寫「7–10 天內、趁腱鞘尚未塌陷」，另一版寫「受傷 2 週內」→ 主答「越快越好，最好 7–10 天內、最遲不超過兩週」，否則肌腱攣縮壞死。
  • Type II：回縮到 PIP 高度（vincula 仍完整）→ ⭐ 這是最常見的一型；時間窗兩版並列（一版「傷後 1 個月仍可嘗試修補」、另一版「6 週內修補」）→ 主答「可容忍到 4–6 週」。
  • Type III：帶大塊撕脫骨片卡在 A4 pulley，回縮有限。
  • Type IV：骨折併肌腱自骨片再撕脫（雙重損傷）。
  • ⚠ 沒有 Type V 這一型。Smith 追加的是上面的 Type IV（肌腱自骨片再度撕脫、可回縮到中節以近甚至手掌；治療是先把骨片固定回遠節，再把撕脫的肌腱推進固定）。～刪除線～原本誤記的第五型：合併 distal phalanx 粉碎性骨折。

【治療】 急性期做 primary repair／reinsertion（pull-out suture 或 bone anchor）。 慢性、已無法直接修補者 → two-stage tendon graft、DIP arthrodesis 或 tenodesis；⚠ 但要先與病人溝通——單獨 DIP 屈曲喪失的功能影響有限，不一定要積極重建。」

追問樹

  • 考官問「Mallet finger 跟它有什麼不同？」 → Jersey ＝ FDP avulsion（屈不起來）；Mallet ＝ 終端伸肌腱在 DIP 止點斷裂或撕脫骨折（伸不直）。Mallet 用 Doyle 分類，治療以 DIP 持續伸直副木 6–8 週（Stack splint）為主，僅在大骨片＋掌側半脫位時手術。
  • 考官問「為什麼 Type I 只有 7–10 天？」 → vincula 是 FDP 的血液供應來源；vincula 一併斷裂後肌腱失去血供、且回縮到手掌後在腱鞘內攣縮，超過 7–10 天就無法拉回原位、也無法存活。
  • 考官問「重建的併發症？」 → quadriga effect（FDP 縫得太緊或太短，因共用肌腹而拖累其他手指的屈曲）、lumbrical-plus finger（肌腱移植過長 → 越用力屈指、PIP 反而伸直的矛盾動作）。
