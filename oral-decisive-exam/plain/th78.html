戒指撕脫傷（Ring avulsion injury; Urbaniak classification）

手外科與周邊神經 · 🟡

一句話定位：撕脫傷的鐵律——血管必須切除到明顯正常的內膜，寧可用 vein graft，也不要在受傷的血管上吻合。

核心模範答案

「報告老師，戒指撕脫傷我用 Urbaniak 分類。

【分類】

  • Class I——循環尚足夠（僅軟組織損傷）。
  • Class II——循環不足，需要 revascularization；可再細分：IIa 只有動脈受損；IIb 動脈加骨骼／肌腱；IIc 靜脈也受損。
  • Class III——完全撕脫（complete degloving）或完全截肢。

⭐ Kay modification 再加入「骨骼是否受傷」這個變數。

【處理】

  • Class I → 保守／清創縫合。
  • Class II → 積極 revascularization；⚠ 常需要 vein graft，因為撕脫傷的血管內膜受損範圍遠超肉眼所見。
  • Class III → replantation 成功率低、結果差，傳統建議 revision amputation；但在拇指或多指的情況下仍應嘗試。

【⭐ 撕脫傷的鐵律】 術中看到 ribbon sign（血管呈緞帶狀彎曲）或 red line sign（血管外壁縱走的紅線），就代表內膜已經受傷——必須切除到明顯正常的內膜，寧可用 vein graft，也不要在受傷的血管上吻合。」

追問樹

  • 考官問「為什麼撕脫傷的成功率低這麼多？」 → ① 血管損傷是「多節段」且遠超外觀 ② 神經同樣被抽拉而長段損傷 ③ 肌腱常自肌肉肌腱交界處撕脫、修補困難 ④ 皮膚 degloving 造成覆蓋不足。
  • 考官問「Class III 一定要截肢嗎？」 → 不一定——拇指或多指時仍應嘗試；⚠ 但要事先與病人溝通成功率與可能需要多次手術、長期復健，以及最終功能可能不如義肢或截肢後重建。
