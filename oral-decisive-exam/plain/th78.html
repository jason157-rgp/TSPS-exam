戒指撕脫傷（Ring avulsion injury; Urbaniak classification）

手外科與周邊神經 · 🟡

一句話定位：撕脫傷的鐵律——血管必須切除到明顯正常的內膜，寧可用 vein graft，也不要在受傷的血管上吻合。

核心模範答案

「報告老師，戒指撕脫傷我用 Urbaniak 分類。

【分類】

  • Class I——循環尚足夠（僅軟組織損傷）。
  • Class II——循環不足，需要 revascularization；可再細分：⭐ Kay（Adani 修訂）分類的正確代號：IIa ＝ 只有「動脈」循環不足；IIv ＝ 只有「靜脈」循環不足。⚠ 沒有 IIb、也沒有 IIc；Class II 的定義是「不完全撕脫、循環不足，但『沒有』骨骼損傷」——一旦合併骨折或關節損傷就升級為 Class III（IIIA／IIIv）。
  • Class III——完全撕脫（complete degloving）或完全截肢〔此為 Urbaniak 的第三級〕。⚠ 在 Kay 分類中，「完全 degloving 或完全截肢」是 Class IV（IVp／IVd／IVi），不是 Class III；Kay 的 Class III 指的是「循環不足『且』合併骨折或關節損傷」。

⭐ Kay（Adani 修訂）分類全文：I ＝ 循環足夠｜II ＝ 不完全撕脫、動脈或靜脈循環不足，「無骨骼損傷」（IIa ＝ 僅動脈、IIv ＝ 僅靜脈）｜III ＝ 循環不足「且合併骨折或關節損傷」（IIIA／IIIv）｜IV ＝ 完全 degloving 或完全截肢（IVp／IVd／IVi）。⭐ 三句話記法：「骨骼受傷就升級 Class III」「靜脈不足是 IIv，沒有 IIc」「完全截肢是 Class IV」。

【處理】

  • Class I → 保守／清創縫合。
  • Class II → 積極 revascularization；⚠ 常需要 vein graft，因為撕脫傷的血管內膜受損範圍遠超肉眼所見。
  • Class III → replantation 成功率低、結果差，⚠ 不要脫口說「傳統就建議 revision amputation」——現行數據已改寫此結論：早期系列報告的存活率是 43%，但近期統合分析顯示手指撕脫性截肢再植的存活率已達 78%，成功再植後平均 TAM 為 174 度，部分研究甚至報到 200 度。因此拇指或多指時應積極嘗試，一般個案也不宜直接勸截肢，但須事先溝通可能需多次手術與長期復健。

【⭐ 撕脫傷的鐵律】 術中看到 ribbon sign（血管被抽拉後呈捲曲的緞帶狀，像禮物上捲起的緞帶）或 red line sign（⚠ 是「皮膚上」沿血管走行的一條瘀血線，代表血管到皮膚的小分支被扯斷、有明顯撕脫成分——不是血管外壁上的紅線），就代表內膜已經受傷——必須切除到明顯正常的內膜，寧可用 vein graft，也不要在受傷的血管上吻合。」

追問樹

  • 考官問「為什麼撕脫傷的成功率低這麼多？」 → ① 血管損傷是「多節段」且遠超外觀 ② 神經同樣被抽拉而長段損傷 ③ 肌腱常自肌肉肌腱交界處撕脫、修補困難 ④ 皮膚 degloving 造成覆蓋不足。
  • 考官問「Class III 一定要截肢嗎？」 → 不一定——拇指或多指時仍應嘗試；⚠ 但要事先與病人溝通成功率與可能需要多次手術、長期復健，以及最終功能可能不如義肢或截肢後重建。

環指要做 arterial transfer 時取哪一條？ 通常取 ulnar digital artery（因為環指的優勢動脈在橈側）；⭐ 取之前要先做 digital Allen test。
