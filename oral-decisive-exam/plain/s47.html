慈濟　李俊達

Ch.C · 顯微重建 · 血管異常與淋巴 · 114 年　顯微重建・淋巴水腫

次專長：檔案未提及；由題目判斷為淋巴水腫顯微手術（LVA／VLNT）與頭頸癌顯微重建（⚠ 推測）。 提問風格：幾乎固定的開場是「你有沒有去過無語良師模擬手術？去過幾次？」——主任非常在意這件事〔多位考生一致，原檔用了三個驚嘆號〕。接著問你實際開過幾台、用哪些皮瓣、幾個 case——這一關考的是「你的個人臨床經驗」，不是教科書。最後才進入淋巴水腫的治療決策。 這關的贏法：主動出擊。兩位考生（國泰陳黎、高醫蕭世奇）都用同一招成功：一進去就先稱讚／提起無語良師模擬手術——「加減拖點時間」，主任會很滿意，後面就變成閒聊。同時，你必須能講出自己 ALT / RFFF / PAP / SCIP / MSAP 的實際案例數與適應症。

固定題組

Q0.（固定開場）「你有沒有去過慈濟的無語良師模擬手術？去幾次？」

模範答案（⭐ 這一題請務必事先準備「你自己的版本」）

建議結構：① 去過幾次、哪幾年 ② 做了哪些操作（例如：head and neck dissection、flap harvest、顯微吻合練習）③ ⭐ 有沒有參加人文儀式（入殮、送靈、感恩追思）④ 今年還會不會去。 〔考生回憶・2025 原始建檔考生的成功版本〕：「每年都有去、還參加過入殮的人文儀式、今年也還會參加一次」→ 主任就很滿意，後面全是聊天。 〔考生回憶・中國家愷〕主任還會主動提「今年的 10/22、10/23 也會去花蓮」。 ⚠ 誠實原則：不要編造。若真的沒去過，改成：「我還沒有機會參加，但我知道慈濟的無語良師是台灣顯微重建訓練最重要的平台之一，尤其是它能做真實組織質地的 flap harvest 與吻合訓練，這是動物模型與模擬器做不到的。我今年已經報名／很希望能參加。」——把它轉成對這個制度的理解與敬意。

Q1.「口腔癌／頭頸癌病人，如果很胖，皮瓣要怎麼選？」〔考生回憶・2025，多位考生同題〕

模範答案（約 120 秒）

「肥胖病人的頭頸重建，核心矛盾是：口腔內腔需要的是薄、柔軟、可摺疊的組織，但肥胖病人可取的皮瓣通常都太厚。我會用三個軸來選：① 缺損的三維需求（面積、厚度、是否需要多葉／複合組織）② 供區的實際厚度 ③ 蒂長與血管口徑是否能安全到達頸部的受區血管。

【各皮瓣在肥胖病人身上的評價】

① ALT（anterolateral thigh flap）— 仍是主力

  • 優點：蒂長（8–16 cm）、口徑好、可取面積大、可做 chimeric（帶 vastus lateralis 做填充或動力）、可帶 fascia lata 做懸吊、可兩組同時進行、供區可直接縫合（寬度 < 8–9 cm）。
  • 肥胖病人的問題：太厚。
  • ⭐ 解法：一期薄化（primary thinning） — 在 Scarpa's fascia 淺層或「superficial fascia」層次修薄（Kimura 的做法），但必須保留 perforator 進入真皮下血管網周圍 1–2 cm 的脂肪袖套（cuff）；或二期 debulking／抽脂〔考生回憶原文：「ALT op 後 debulking」〕。⚠ 過度一期薄化在肥胖病人有部分壞死風險，我會傾向保守薄化 + 計畫性二期修薄。

② RFFF（radial forearm free flap）— 肥胖病人的最佳「薄」選擇

  • 優點：⭐ 前臂的皮下脂肪厚度受全身肥胖影響最小，是最薄、最柔軟、可摺疊的選擇；蒂長、口徑大、解剖恆定、可做感覺皮瓣（外側前臂皮神經）、可帶橈骨做骨皮瓣。
  • 缺點：供區醜（需植皮）、犧牲一條主要血管（術前必做 Allen's test）、橈骨取骨有病理性骨折風險、面積有限。
  • ⭐ 適應症：口底、頰黏膜、舌部分切除、需要薄且可摺的內襯——在肥胖病人身上，RFFF 的相對價值反而上升。

③ SCIP（superficial circumflex iliac artery perforator flap）

  • ⭐ 最薄的選擇之一（可做到 super-thin，在 Scarpa's fascia 之上）、供區疤痕可藏在比基尼線、可直接縫合、幾乎無功能犧牲。
  • 缺點：蒂短、血管口徑細（需要良好的顯微技術與合適的受區血管）、解剖變異大（deep vs superficial branch）。
  • 〔考生回憶・2025 中國家愷〕主任會追問「都用在哪邊？medial 還是 lateral branch 的選擇？」——要能答：superficial branch 走向外上、位置較淺，適合取薄皮瓣；deep branch 較粗、可帶髂骨。

④ MSAP（medial sural artery perforator flap）

  • 優點：薄、柔軟、無毛、顏色質地適合口內；蒂長約 8–12 cm、口徑尚可；供區隱蔽。
  • 缺點：穿支變異大、解剖較費時、面積受限、供區有時需植皮。
  • 〔考生回憶〕成大姜良叡被問「MSAP 的經驗與臨床應用」。

⑤ PAP（profunda artery perforator flap）

  • 大腿後內側；在部分亞洲女性可以比 ALT 更薄、疤痕隱藏在臀摺下方；在肥胖病人可能仍偏厚，需個別評估。

【我的結論句】 「所以在肥胖的口腔癌病人，我的順位會是：內襯需要薄且可摺 → RFFF 或 SCIP；面積大、需要體積或多葉重建 → ALT（一期保守薄化 + 計畫性二期 debulking）；需要中等面積且薄、又想避免前臂供區 → MSAP。」

追問串

  • 「你自己做了多少案例？」〔考生回憶：主任明確問過「問我做了多少案例」〕→ ⭐ 誠實給數字，並補上一個具體的 case 記憶點（哪個缺損、選什麼、術後如何、有沒有併發症、學到什麼）。
  • 「你們醫院都開什麼 flap 做重建？」 → 講自家常規 + 為什麼這樣選。
  • 「SCIP 用 medial 還是 lateral branch？」 → 如上。

加分句

「我的實務原則是『先決定厚度，再決定血管』——因為在肥胖病人身上，厚度是唯一無法在術中補救的變數；蒂長不夠可以接 vein graft，口徑不合可以做 end-to-side，但皮瓣太厚會直接讓病人吞不下去、講不出話。」

Q2.「淋巴水腫要怎麼治療？LVA 還是 VLNT？」〔考生回憶・2025，成大姜良叡＋高醫蕭世奇〕

模範答案（⭐ 決策樹，可逐字講，約 120 秒）

「淋巴水腫的治療決策，我會分成四步：① 確診與排除鑑別診斷 ② 分期 ③ 影像決定『淋巴管還有沒有功能』 ④ 依據前三步選擇術式。

【① 確診與鑑別】

  • 病史：續發性最常見的成因是癌症治療（手術淋巴結廓清 + 放療）；原發性則依發病年齡分為 congenital（含 Milroy，約 10–25%）／praecox（⭐ 最多，GS 給 80%）／tarda（約 10%）〔本專案衝突總表・TB-V1-01：「先天型最多」是錯的〕。
  • 鑑別：靜脈疾病（CVI、DVT）、心衰／腎病／肝病造成的全身性水腫、lipedema、惡性腫瘤壓迫。
    • ⭐ Lipedema 的鑑別口訣：足與腳趾受累 → lymphedema；足趾倖免 → lipedema。
    • ⚠ Stemmer sign 陰性不能排除診斷。
  • ⚠ 利尿劑不是首選——淋巴水腫的液體是高蛋白的，利尿劑排掉水、蛋白留下，滲透壓更高、纖維化更快。首選是 CDT。

【② 分期 — ISL 只有四期】

  • Stage 0（subclinical）：淋巴輸送已受損但外觀無腫脹。
  • Stage I：凹陷性水腫（pitting），抬高可完全消退。
  • Stage II：抬高不能完全消退；晚期可以是非凹陷性且已有組織纖維化。
  • Stage III（lymphostatic elephantiasis）：象皮病外觀——棘皮症、疣狀增生、皮膚皺褶加深、大量脂肪堆積。
  • ⚠ 本專案衝突總表 TB-V1-03/04 的重點：「非凹陷 + 纖維化」而未提象皮病外觀者，學理上可歸 Stage II；ISL 沒有 Stage IV 或 V——看到 IV 想 Cheng 或 MDACC，看到 V 想 Campisi。

【③ 影像 — ⭐ 這是決定 LVA 還是 VLNT 的關鍵，也是主任 2025 年要的答案】 〔考生回憶・高醫蕭世奇原文〕：「先用 lymphoscintigraphy 看 lymph vessel 是否有 function，有 function 才做 LVA，沒有的話考慮 VLNT；advanced stage 考慮做 volume reduction。」

  • Lymphoscintigraphy（淋巴閃爍造影）：判斷淋巴引流是否通暢、有無 dermal backflow、淋巴結攝取情形、是 partial 還是 total occlusion（partial／total occlusion 是 Cheng 分級的用語）。
  • ICG lymphography（吲哚菁綠淋巴造影）：現代術中與術前規劃的主力。Yamamoto 的 DB（dermal backflow）分期：linear（正常，淋巴管仍有功能）→ splash → stardust → diffuse（越後面代表功能越差）。⭐ 有 linear pattern 才是 LVA 的好對象。
  • 高解析度超音波 / MR lymphangiography：找可用的淋巴管與確認靜脈狀況。

【④ 術式選擇】

甲、保守治療是所有人的第一線與終身基礎 — CDT（complete decongestive therapy）

  • Phase 1（reductive，減量期）：由認證淋巴治療師（CLT）主導，徒手淋巴引流（MLD）＋ 短彈性繃帶（short-stretch bandaging）＋ 皮膚照護 ＋ 運動。
  • Phase 2（maintenance，維持期）：終身壓力衣 ＋ 自我引流 ＋ 皮膚照護。
  • ⭐ 沒有做過完整保守治療的病人，不該直接談手術。

乙、生理性（physiologic）手術 — 適用於還有可用淋巴管、以早中期為主

  • LVA（lymphaticovenular anastomosis，淋巴管靜脈吻合）
    • 適應症：ISL Stage I–II 早期、ICG 仍見 linear pattern、淋巴管管腔尚未纖維化、有適合的細小靜脈（壓力低、無逆流）。
    • 優點：局部麻醉可做、切口小、無供區併發症、可重複。
    • 原理：把功能仍存的淋巴管接到皮下細靜脈，繞過阻塞。⭐ 成功的關鍵是「靜脈端壓力必須低」，否則血液會逆流塞住吻合口。
  • VLNT（vascularized lymph node transfer，帶血管淋巴結移植）
    • 適應症：⭐ 淋巴管已無功能（ICG 呈 stardust/diffuse、lymphoscintigraphy 顯示阻塞）、或 LVA 失敗、或需同時做乳房重建者。
    • 供區：腹股溝（superficial groin）、鎖骨上（supraclavicular）、頷下（submental）、大網膜（omental / gastroepiploic，⭐ 沒有醫源性淋巴水腫風險的優點）、腸繫膜。
    • ⭐⭐ 最大風險：供區醫源性淋巴水腫 → 必須做反向淋巴繪圖（reverse lymphatic mapping）避開肢體引流的淋巴結。
    • 受區位置的兩派：接在遠端（腕部／踝部，利用重力與「幫浦」理論） vs 接在近端（腋窩／腹股溝，同時做疤痕鬆解、重建解剖通路）——兩派都有支持證據，⚠ 目前無定論。
  • ⭐ 現代趨勢：LVA + VLNT 併用（combined physiologic approach），或同時合併抽脂。

丙、減積（debulking / excisional）手術 — 適用於晚期、以脂肪與纖維化為主的肢體

  • ⭐ 抽脂（suction-assisted lipectomy，Brorson 術式）：適用於非凹陷性、以脂肪堆積為主、生理性手術無法再改善的病人；⭐ 術後必須終身穿壓力衣，否則一定復發。
  • 切除性手術（Charles procedure、Sistrunk、Homans）：保留給極重度、皮膚已嚴重病變者，併發症多，現代已少用。
  • ⭐ 上下肢的反轉關係（本專案手冊列為重點）：引流手術在上肢佔優（下肢有下垂姿勢與較高靜脈壓）；減積手術在下肢佔優（下肢整體減積效果約 52%，上肢的腕部 0.5%、手部 3.6% 幾近無效）。

丁、預防（現代最重要的觀念轉向）

  • ⭐ 立即淋巴重建（ILR）／LYMPHA（lymphatic microsurgical preventive healing approach）：在腋下淋巴結廓清的當下，把被切斷的傳入淋巴管接到腋靜脈的分支。文獻報告可至少降低 50% 的發生率。
  • ⚠ 療效解讀鐵則：ALND 後 2 年才是乳癌相關淋巴水腫的發病高峰——追蹤未滿 2 年的療效宣稱都要保守解讀。
  • ⚠ transient edema：術後 > 2 週才出現、多在 6 個月內緩解，不等於失敗。

【總結一句】 「保守治療是地基，影像決定路線：淋巴管還活著就走 LVA、死了就走 VLNT、已經變成脂肪就走抽脂，三者現在越來越常合併使用。」」

加分句

「淋巴水腫治療最現代的轉向，是從『得了病之後怎麼救』變成『在腋下廓清的當下就先接起來』——也就是 LYMPHA／ILR。這也是為什麼我認為整外應該在乳癌手術的當下就到場，而不是等到病人腫起來才被會診。」

⚠ 李俊達這關的地雷

  1. 沒去過無語良師模擬手術、或講不出去了幾次（⚠ 推測，但檔案顯示他非常在意，原檔用了三個驚嘆號）。
  2. 講不出自己的實際案例數——這關考的是你的經驗，不是教科書。請在考前把自己的 ALT / RFFF / PAP / SCIP / MSAP 案例數與代表性 case 各準備一句話。
  3. 把淋巴水腫講成「就是穿壓力衣」——他要的是 lymphoscintigraphy → LVA vs VLNT vs volume reduction 的完整決策樹。
  4. ⚠ ISL 分期講到 Stage IV 或 V——ISL 只有 0/I/II/III。

若他 2026 年換題：依「淋巴 + 頭頸顯微」推測（⚠ 全為推測）

⚠ 推測題 骨架答案
① 口腔癌重建的整體策略（依缺損分區） 舌部分切除 → RFFF／SCIP（薄、可摺）；半舌或全舌 → ALT（需體積維持吞嚥）；頰黏膜貫穿性缺損 → 雙葉或 chimeric ALT（內襯 + 外覆）；下顎節段性缺損 → free fibula osteocutaneous（可做雙管 double-barrel 恢復高度、可植牙）；上顎缺損 → 依 Brown 分類選 obturator 或 free flap。
② Free flap 術後監測與搶救 傳統（顏色、溫度、capillary refill、針刺出血顏色、Doppler）+ 現代（植入式 Doppler、近紅外光譜 NIRS、ICG）；⭐ 靜脈阻塞比動脈阻塞常見且進展快（皮瓣暗紫、腫脹、針刺出暗血）；搶救的黃金時間內回開刀房，探查吻合口 → 取出血栓 → 重接或 vein graft → 可考慮 thrombolytic（urokinase/tPA）灌注 → leech（水蛭）用於靜脈鬱血；⭐ 最容易出問題的步驟其實是 flap inset 與蒂部擺位（扭轉、壓迫），不是吻合本身〔考生回憶・111 洪學義關〕。
③ 淋巴水腫的診斷數值 ⚠ 舊定義「周徑差 ≥ 2 cm」已被容積取代：現行主要採體積差 > 200 mL 或 > 10%；GS 分度：輕 < 20%／中 20–40%／重 > 40%〔本專案衝突總表 TB-V1-05〕。
④ 乳癌相關淋巴水腫的風險數字 ALND 約 20–50%、SLNB 約 3–25%（SLNB 可降至 6–8% 但不等於零）；BMI > 30 → 3 倍；放療 → 5 倍且與手術有加成；乳癌後平均 8 個月發病、75% 在 3 年內；約 40% 病人有反覆蜂窩組織炎。
⑤ 慈濟的在地特色：偏遠醫療與大體模擬手術的教育角色 可談模擬手術對顯微訓練的不可取代性、人文儀式對外科醫師養成的意義——⚠ 這題可能以閒聊形式出現，準備一段真誠的個人心得比背資料有效。
