其他顏面骨折型：Le Fort、NOE 與額竇（Le Fort / NOE / frontal sinus fracture）

顱顏與顏面外傷 · 🟡

一句話定位：外傷站的「延伸備援題」——三型 Le Fort 都過翼板、NOE 看 Markowitz 與內眥韌帶、額竇看 outflow tract。

核心模範答案

【Le Fort I / II / III】 ・Le Fort I（Guerin，horizontal）：上顎齒槽骨段與上顎骨體分離，骨折線橫過梨狀孔下方、上顎竇前外側壁、翼板；臨床可見上顎搖動測試時只有齒槽段動、鼻根不動。 ・Le Fort II（pyramidal）：骨折線經鼻額縫 → 眶內側壁與眶底 → 眶下緣 → ZM buttress → 翼板；搖動時鼻根跟著動；常見 CSF 鼻漏、眶下神經麻木。 ・Le Fort III（craniofacial disjunction）：經鼻額縫 → 眶內側壁 → 眶底 → ZF suture → 顴弓 → 翼板，整個顏面與顱底分離；搖動時整個中臉連顴骨一起動。 ・⭐ 三型都會通過 pterygoid plate——這是與 ZMC 骨折最大的區別；ZMC 不累及翼板，也不直接影響咬合。 ・⭐ palate fracture 一定合併 Le Fort（複合型）；medial pterygoid 會把齒槽骨段往下外拉，臨床上出現 Class III 咬合／anterior open bite／臼齒早接觸。

【NOE fracture（naso-orbito-ethmoid）】 ・⭐ Markowitz I–III 分類，依「medial canthal tendon 與骨塊的關係」：I 型＝單一大骨塊、韌帶附著完整；II 型＝粉碎但韌帶仍附著在可辨識的骨片上；III 型＝粉碎且韌帶自骨片撕脫。 ・正常 intercanthal distance 30–34 mm；telecanthus 是軟組織／內眥韌帶的問題，hypertelorism 是骨性眶距過寬——兩者不可混用。 ・檢查：bowstring test（往外拉眼角、同時觸診內眥韌帶有無鬆動）與 bimanual palpation（一手器械經鼻內、一手在內眥外觸診）。 ・治療要點：transnasal wiring，且鉤點必須在淚囊窩的「後上方」——否則會把內眥拉向前下，做不出正常的內眥形態。

【Frontal sinus fracture】 ・分前壁、後壁、與 fronto-nasal duct（outflow tract）三個問題。 ・⭐ duct 是否受損是決定術式的關鍵：duct 完整、僅前壁移位 → 復位固定；duct 受損 → obliteration（去除黏膜後填塞）；後壁粉碎、硬腦膜破損或 CSF 漏 → cranialization（顱腔化：移除後壁與所有黏膜、封閉 nasofrontal duct、以 pericranial flap 隔開顱腔與鼻腔）。 ・⚠ 晚期併發症：多年後眉上腫塊 → fronto-ethmoidal mucocele／mucopyocele，處理是 cranialization 或 marsupialization；也可能出現腦膜炎、腦膿瘍。

追問樹

  • 考官問「怎麼分辨 ZMC 和 Le Fort？」 → 你答：看有沒有累及翼板與咬合——三型 Le Fort 都過 pterygoid plate 且影響咬合；ZMC 不會。
  • 考官問「NOE 怎麼判斷嚴重度？」 → 你答：Markowitz 分型，關鍵在內眥韌帶是否還附著在可用的骨片上（III 型必須 transnasal wiring 重新固定韌帶）。
  • 考官問「病人眼距變寬，是 telecanthus 還是 hypertelorism？」 → 你答：量 intercanthal distance（正常 30–34 mm）與 interpupillary／interorbital distance；外傷後絕大多數是 telecanthus（韌帶／軟組織），hypertelorism 是骨性、多為先天。
  • 考官問「額竇骨折什麼時候要 cranialization？」 → 你答：後壁粉碎移位、硬腦膜破損或持續 CSF 漏、或 outflow tract 無法保留時。
