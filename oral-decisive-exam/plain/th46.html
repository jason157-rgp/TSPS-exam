爪形手的四層治療階梯與動態肌腱轉移（Treatment ladder for claw hand）

手外科與周邊神經 · 🔴

一句話定位：一開口就講 tendon transfer 是本題最大的地雷——順序永遠是保守 → 神經 → 神經轉移 → 肌腱轉移。

核心模範答案

「報告老師，我分四層。

【第一層｜保守治療——永遠不能跳過的一層】 anti-claw splint（lumbrical bar／figure-of-eight splint）：作用是阻擋 MCP 過度伸直，讓 extensor 的力量能傳遞到 IP，同時也是功能性輔具。 ⚠ 最重要的目的是「預防 PIP 形成固定的屈曲攣縮」——因為一旦 PIP 攣縮，後面所有的神經或肌腱重建都不會成功。加上積極的被動運動與 hand therapy。

【第二層｜神經層次】 壓迫性病變 → in situ decompression 或 anterior transposition。 斷裂 → 無張力的 primary epineurial repair；有缺損 → sural nerve graft；缺損 3 公分以內也可考慮 conduit 或處理過的 nerve allograft。

【第三層｜神經轉移（nerve transfer）】——適用於損傷位置太近端、軸突來不及在終板退化前抵達者。 AIN 的末端（到 pronator quadratus 的分支）→ ulnar nerve 的 deep motor branch，做 supercharge end-to-side。時機是受傷後 6 到 12 個月內、越早越好。

【第四層｜肌腱轉移（tendon transfer）】——適用於超過 12 到 18 個月、內在肌已不可逆萎縮者。先做 Bouvier maneuver 分類。

【動態 transfer 的 donor——最常用的是 FDS】

  • 1. Zancolli lasso procedure（最標準）：把 FDS 從 A1 pulley 的近端拉出，繞過 A1 pulley 後折回縫到自己身上，形成套索。收縮時拉緊 A1 pulley、直接在 MCP 產生屈曲。優點：手術簡單、不需肌腱移植、不必進到手指裡。適用 Bouvier 陽性的 simple claw。
  • 2. Modified Stiles–Bunnell：取中指或環指的 FDS，縱向分成數束，經 lumbrical canal 插到環指與小指的「橈側 lateral band」。同時提供 MCP 屈曲與 IP 伸直 → 適用 Bouvier 陰性的 complex claw。⚠ FDS 取太多會造成 donor 手指 swan-neck deformity，所以要保留 FDS 在中節指骨的部分止點。
  • 3. Brand transfer（EF4T／EE4T）：ECRL 或 ECRB ＋ 肌腱移植，經 intermetacarpal space 或背側繞到 lateral band。

【靜態做法】：Zancolli volar plate capsulodesis 或 MCP volar tenodesis——單純阻擋 MCP 過度伸直，適用 Bouvier 陽性、活動需求不高者。

【常一起問的另外三個 transfer】

  • 矯正 Froment's sign（拇指內收無力）→ ECRB ＋ 肌腱移植 → adductor pollicis。
  • 矯正 Wartenberg's sign（小指持續外展）→ EDM 尺側半條 → 小指 A1／A2 pulley，或縫到橈側 collateral ligament。
  • 矯正食指外展無力 → EIP → 第一背側骨間肌。
  • 高位損傷造成的環指、小指 FDP 無力 → 側縫到中指的 FDP（side-to-side）。」

追問樹

  • 考官問「做 tendon transfer 之前要確認什麼？」 → 七大原則：「① 傷口穩定、關節柔軟、無攣縮 ② donor 肌力至少 M4–M5（transfer 後一定掉一級）③ amplitude 匹配——手腕約 25–33 mm、伸指肌約 50 mm、屈指肌約 70 mm（記憶：3-5-7）④ 直線牽引 ⑤ 一條肌腱只做一個功能 ⑥ 盡量選協同（synergistic）肌肉 ⑦ donor 必須可犧牲。」
  • 考官問「三前提是什麼？」（陳理維版）→ 關節被動活動度完整、軟組織床穩定無疤痕、donor 肌力至少 MRC 4 級以上且功能可犧牲。
  • 考官問「FDS 取太多會怎樣？」 → donor 手指 swan-neck deformity；另外要警覺 quadriga effect（FDP 共用肌腹，過度縮短會讓其他指也屈不完全）與 lumbrical-plus finger。
