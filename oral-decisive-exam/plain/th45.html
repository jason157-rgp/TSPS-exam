Bouvier test 與 simple vs complicated claw（Bouvier maneuver）

手外科與周邊神經 · 🔴

一句話定位：它不是診斷工具，是「術式分流器」——決定 transfer 插不插到 lateral band。

核心模範答案

「報告老師，在做任何 tendon transfer 之前，我一定先做 Bouvier maneuver 來分類。

【做法】 檢查者擋住 MCP 的過度伸直（把 MCP 被動屈曲固定住），然後請病人主動伸直 PIP 與 DIP。

【判讀與其臨床決策——這才是考點】

  • 能主動伸直 → 「simple claw／supple claw」（Bouvier 陽性）：代表 extensor mechanism 本身是完好的，變形純粹來自 MCP 失去屈曲的拮抗。

→ 我的 transfer 只需要「在 MCP 產生屈曲」就好——可以插到 A1 或 A2 pulley、或插到 proximal phalanx，「不需要」插到 lateral band。 → 可以走 static procedure（Zancolli volar plate capsulodesis、MCP volar tenodesis、bone block） 或 Zancolli lasso。

  • 擋住 MCP 之後 IP 仍伸不直 → 「complicated / complex claw」（Bouvier 陰性）：代表 extensor mechanism 已經失效或有續發攣縮。

→ 必須把 transfer 一路插到 lateral band，才能同時提供 IP 的伸直力量 → dynamic procedure（modified Stiles–Bunnell、Brand）。

【背後的原理】 擋住 MCP 等於人工替代了 intrinsic 在 MCP 的屈曲作用；此時 extensor 的力量不再被「消耗」在 MCP 這個關節上，就能傳遞到遠端的 IP。所以病人能不能伸直 IP，測的其實是「extensor mechanism 的完整性」。」

追問樹

  • 考官問「Simple claw 的 transfer 要插在哪裡？」 → 〔考生回憶‧104 邱浩遠同題〕「Bouvier 陽性代表只要在 MCP 產生屈曲即可，所以肌腱插到 A1／A2 pulley 或 proximal phalanx 就夠，不必插到 lateral band。」
  • 考官問「怎麼確定它是 claw finger 而不是別的？」 → 〔考生回憶‧邱浩遠版〕「把 MCP 從過度伸直的位置壓平固定住，PIP 與 DIP 就自然伸直了 → 證明是 lumbrical weakness。」
  • 考官問「Bouvier 陰性一定是 extensor 壞掉嗎？」 → 要先排除 PIP 已形成固定的屈曲攣縮——攣縮的關節是 tendon transfer 的絕對禁忌，必須先復健把被動活動度做回來，再談手術。
