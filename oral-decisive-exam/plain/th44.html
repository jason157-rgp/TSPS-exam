尺神經六大徵象與其機轉（Six signs of ulnar nerve palsy）

手外科與周邊神經 · 🔴

一句話定位：只講名字必被追問機轉——這一題的評分點是「能不能邊做邊講為什麼」。

核心模範答案

「報告老師，尺神經的徵象我一邊做一邊講機轉。

徵象 表現 機轉（⚠ 一定要講）
Froment's sign 用拇指與食指側面捏紙時，拇指 IP 關節屈曲 adductor pollicis 與第一背側骨間肌無力 → 病人改用 median／AIN 支配的 FPL 代償，於是 IP 彎起來
Jeanne's sign 同一動作時拇指 MCP 過度伸直 adductor 無力使 MCP 不穩，EPL 代償造成 MCP hyperextension；常與 Froment 併存
Wartenberg's sign 小指持續外展、無法與環指併攏 第三 palmar interosseous（內收小指）無力，而 radial nerve 支配的 EDM（有外展作用）失去對抗
Duchenne's sign 環指與小指 MCP 過度伸直 ＋ IP 屈曲（＝ clawing 本身） 第 3、4 lumbrical 與 interossei 失能 → EDC 在 MCP 無拮抗、FDS/FDP 在 IP 無拮抗
André–Thomas sign〔⭐ 本次新增，兩本教科書都明列，優先背這一個〕 病人想用「掌屈手腕」的 tenodesis 效應去伸直手指，結果反而讓 claw 更嚴重 extensor tendon 的 tenodesis 代償無效，反而加重 MCP hyperextension 與 IP flexion
Masse's sign〔⚠ 兩本教科書全文皆無 "Masse"，屬臨床常用說法，可講但不可宣稱課本明文〕 掌弓（metacarpal arch）變平、小指掌骨無法下沉 opponens digiti minimi 與 hypothenar 群無力／萎縮
Pitres–Testut sign 無法把中指向兩側偏移、做不出「金字塔／牛角」手勢 interossei（手指外展與內收）無力

另外兩個一定要一起講的：

  • Bouvier maneuver：擋住 MCP hyperextension 後，IP 能主動伸直＝simple claw；不能＝complex claw——它決定 tendon transfer 要不要插到 lateral band。
  • Card test〔⚠ 「Egawa test ＝ 夾紙」查不到明文；兩指相交叉的正式名稱是 "crossed fingers" sign〕：兩指之間夾紙、或手指主動外展內收，快速篩檢 interossei 力量。

⭐ 最後我會補一句指標肌：第一背側骨間肌是最容易目視、也最不會被其他神經代償的指標肌〔考生回憶‧108 新光關考官明說：「大家都有管到的功能很難區分，最好測 first dorsal interosseous」〕。」

追問樹

  • 考官問「Wartenberg's sign 是哪一條神經？」 → ulnar。⚠ 但講法要有次序：「這個表現最符合 interosseous muscle 的無力，我第一個懷疑 ulnar nerve；但若合併 thenar 萎縮與拇指對掌困難，就要一併考慮 median nerve 的合併損傷。」
  • 考官問「Froment 為什麼會 IP 屈曲？」 → adductor pollicis 無力 → FPL 代償；FPL 由 AIN（median）支配，所以尺神經壞掉時它還在。
  • 考官問「怎麼矯正這些徵象？」 → Froment（拇指內收無力）→ ECRB ＋ 肌腱移植轉到 adductor pollicis；Wartenberg（小指持續外展）→ EDM 尺側半條轉到小指 A1/A2 pulley 或縫到橈側 collateral ligament；食指外展無力 → EIP 轉到第一背側骨間肌。

各考官問法差異

考官 年份 他的切入點 他偏好的答案／地雷
林口長庚 林有德 2025 逐條問，且要求「邊做邊講機轉」 ⚠ 只講名字會被繼續追問

台中慈濟 簡守信 107・110・111 影片：手指伸直時無法併攏／夾不緊紗布 要能一次講出 Wartenberg ＋ Froment ＋ Jeanne 三者
成大 李經維 107 「用你的手比一下 ulnar nerve injury 的表現」 當場比出環指小指 MCP hyperextension + IP flexion，同時口述五大徵象

⚠ 衝突與裁決 Wartenberg's sign 的神經歸屬（衝突表 #27）：多數考生記 ulnar；另有考生記成「median nerve neuropathy, weakness 2nd web, MP compensatory hyperextension」。 裁決：以 ulnar 為準——小指外展是因為尺神經支配的第三 palmar interosseous（內收小指）無力，而橈神經支配的 EDM（有外展作用）失去對抗。 考場講法：先完整描述你看到的動作，再說「最符合 interosseous muscle 的無力，我第一個懷疑 ulnar；若合併 thenar 萎縮與對掌困難，要一併考慮 median 的合併損傷」——這樣兩份答案卡你都涵蓋。

🗂 考場問答速查

考官會問 你要答
把尺神經的徵象邊做邊講機轉。 Froment：側捏紙時拇指 IP 屈曲 → adductor pollicis 與第一背側骨間肌無力，改用 median／AIN 支配的 FPL 代償。Jeanne：同一動作拇指 MCP 過度伸直 → adductor 無力使 MCP 不穩、EPL 代償，常與 Froment 併存。Wartenberg：小指持續外展 → 第三 palmar interosseous 無力，radial 支配的 EDM（有外展作用）失去對抗。Duchenne：環小指 MCP 過度伸直＋IP 屈曲（＝clawing）→ 第 3、4 lumbrical 與 interossei 失能。Pitres–Testut：中指無法向兩側偏移、做不出「金字塔」手勢 → interossei 無力。
追問：還有沒有其他 sign？ André–Thomas sign（一定要補進來）：病人想用 腕掌屈的 tenodesis 效應去伸直手指，結果反而讓 claw 更嚴重。＋Bouvier maneuver（擋住 MCP hyperextension 後 IP 能否主動伸直 → simple vs complex claw）。
追問：Masse's sign 呢？ 可以講：掌弓變平、小指掌骨無法下沉（ODM 與 hypothenar 群無力）——但這是臨床常用說法，被追問出處時說「這是臨床上常見的稱呼」，不要宣稱是課本明文。〔記憶點，非課本明文〕
追問：Card test／Egawa test？ 概念可用：兩指之間夾紙、或主動外展內收快速篩檢 interossei。⚠ 「Egawa test＝夾紙」查不到明文；兩指交叉的正式名稱是 "crossed fingers" sign。〔記憶點，非課本明文〕
Wartenberg's sign 是哪一條神經？ ulnar。⚠ 但講法要有次序：「這個表現最符合 interosseous muscle 無力，我第一個懷疑 ulnar nerve；若合併 thenar 萎縮與對掌困難，就要一併考慮 median nerve 的合併損傷。」——這樣兩份答案卡都涵蓋。
Froment 為什麼會 IP 屈曲？ adductor pollicis 無力 → FPL 代償；FPL 由 AIN（median） 支配，尺神經壞掉時它還在。
怎麼矯正這些徵象？ Froment → ECRB（或 BR）＋ 肌腱移植繞第三掌骨當 pulley → adductor pollicis；Wartenberg → EDM 尺側半條 → 小指 A1／A2 pulley 或縫到橈側 collateral ligament；食指外展無力 → EIP → 第一背側骨間肌。
最後補一句指標肌？ 第一背側骨間肌是最容易目視、也最不會被其他神經代償的指標肌。
