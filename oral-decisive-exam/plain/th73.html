板機指與 A1 pulley 注射（Trigger finger/thumb; A1 pulley injection）

手外科與周邊神經 · 🔴

一句話定位：簡守信 104–111 每年必出的影片題，而他真正追問的是「local 要打在哪裡」這個操作細節。

核心模範答案

「報告老師，影片中病人主動伸直拇指時出現卡頓與彈跳（triggering／locking），被動可以扳直，臨床診斷是 trigger thumb（stenosing tenosynovitis）。

【病理機轉】 FPL 肌腱與 A1 pulley 之間的「大小不匹配」——A1 pulley 增厚纖維化、肌腱形成結節（Notta's node），導致肌腱通過 pulley 時卡住。⭐ A1 pulley 位於 MCP joint 的掌側。

【理學檢查】 在 MCP joint 掌側（拇指的 A1 pulley 處）可摸到壓痛的結節，並可在被動屈伸時感受到 crepitus。 分級用 Green classification：I 疼痛／II 可主動 catching／III 需被動 unlock／IV 固定攣縮。

【治療階梯】 ① 保守：activity modification、NSAID、夜間 MCP extension splint； ② 局部類固醇注射——首選的非手術治療，成功率約 60–90%，可重複 1 到 2 次； ③ 手術：A1 pulley release（open 或 percutaneous）。」

追問樹

  • 考官問「Local 要打在哪裡？」 → ⭐ 他一定會問的操作題：「打在 A1 pulley 的位置，也就是拇指 MCP joint 的掌側橫紋處，從掌側（volar）垂直進針，藥物可沿腱鞘擴散到 A1 與 oblique pulley 附近即可。」〔考生回憶〕考生問「要不要從 dorsal side？」→ 院長：「不用，在 MC base 可以直接 volar 該位置局部打」「直接在 A1 和 oblique pulley 附近打」。
  • 考官問「有什麼安全上的注意？」 → ⚠ 加分句：「拇指的 radial 與 ulnar digital nerve 在 A1 pulley 這個高度非常表淺且靠近中線，所以要從正中線垂直進針，避免傷到指神經；注射時不要在阻力極大時強推，以免打進肌腱實質造成 rupture。」
  • 考官問「拇指的 pulley 跟其他手指有什麼不同？」 → 拇指只有兩條 annular pulley（A1、A2）加上一條 oblique pulley；⭐ oblique pulley 是拇指最重要的 pulley，release 時「必須保留」，切斷會造成 bowstringing 與 IP 屈曲力量喪失。
  • 考官問「小兒 trigger thumb 呢？」 → 多數在 1 歲前可自行緩解，可先觀察與被動伸展；持續固定屈曲攣縮者建議 A1 pulley release，一般在 1–3 歲之間手術。
