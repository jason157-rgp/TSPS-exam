林口長庚　林承弘

Ch.E-6 · 顯微重建 · 111 年　顯微重建・VCA

📇 林口長庚官網・林承弘醫師簡介（含照片）　整形外科系系主任、教授；肢體與顯微重建、手外科、複合組織異體移植（手／臉移植）

  • 次專長：⭐ 上下肢肢體重建、顯微重建手術、手外科、異體複合移植（VCA——上肢與臉部移植）。
  • 學經歷：長庚整形外科系系主任、長庚醫院教授；台灣手外科醫學會理事、台灣顯微重建外科醫學會常務理事；⭐ 匹茲堡大學與約翰霍普金斯大學的異體複合移植（VCA）研究員。
  • ⭐ 最該準備的方向（原檔明列的猜題）： 1. ⭐ Medial sural artery perforator（MSAP）flap ——建議閱讀他們團隊的 《The Medial Sural Artery Perforator Flap: Lessons Learned from 200 Consecutive Cases》Plast Reconstr Surg. 2020 Nov;146(5):630e-641e. > 要點：血管蒂為 medial sural artery（膕動脈的分支），從腓腸肌內側頭穿出；蒂長約 8–15 cm、口徑 1.5–2 mm；皮島薄（約 5–8 mm）、質地佳、供區可直接縫合（寬度 < 5–6 cm 時）。⭐ 適應症：口腔／舌／頰黏膜的中小型缺損（比 ALT 薄、比 radial forearm 供區病態低）、手足的薄型覆蓋、部分咽喉重建。缺點：穿支解剖變異大（術前建議 Doppler 或 CTA 定位）、剝離需穿過肌肉、皮島寬度受限。 2. ⭐ Hand transplantation 與 VCA 的免疫學 ——準備 hyperacute／acute／chronic rejection 的症狀、診斷與治療：
    • ⭐ Hyperacute rejection：術後數分鐘至數小時，預存抗體（preformed antibody）造成的補體活化與血管栓塞，移植物立即壞死；預防靠術前 ABO 配對與 crossmatch，發生後無法挽救。
    • ⭐ Acute rejection（VCA 最常見，第一年約 85% 至少發生一次）：皮膚是最早也最靈敏的標的器官（「皮膚是 VCA 的哨兵」）；表現為 紅斑、丘疹、水腫、脫屑；診斷靠 皮膚切片 + Banff 2007 VCA 分級（Grade 0 無／I 輕度血管周圍浸潤／II 中度／III 重度含表皮凋亡與 dyskeratosis／IV 壞死）；治療是 高劑量類固醇脈衝、局部 tacrolimus／clobetasol 藥膏、必要時 antithymocyte globulin 或 alemtuzumab。⭐ 預後好，絕大多數可完全逆轉。
    • ⭐ Chronic rejection：表現為 移植物血管病變（graft vasculopathy）——內膜增生、管腔狹窄，臨床上出現皮膚硬化與萎縮、指甲變化、脫毛、肌肉萎縮與纖維化、功能逐漸退化；⚠ 目前沒有有效治療，是 VCA 長期存活的主要限制。
    • 免疫抑制的標準三聯方案：tacrolimus + mycophenolate mofetil + steroid，加上誘導期的 antithymocyte globulin 或 alemtuzumab（⭐ 匹茲堡的 Starzl protocol 主張以 alemtuzumab 誘導 + tacrolimus 單一藥物維持）。⚠ VCA 的最大倫理爭議：這是一個「非救命（non-life-saving）」的手術，卻要付出終身免疫抑制的代價（感染、腎毒性、糖尿病、惡性腫瘤），所以病人選擇與知情同意極為關鍵。 3. 上下肢重建的一般原則：defect 分析、reconstruction ladder／elevator、perforator flap 的選擇邏輯。
  • ⚠ 應對：〔原檔〕「不笑的時候看起來嚴肅。邏輯和思緒清晰。有原則，感覺上應該不會太刁難大家。」→ ⭐ 對邏輯清晰的考官，最好的策略是「先給架構，再填內容」——先說「我分三個層面回答」，再逐項展開。

  • ⚠ 應對：〔原檔〕「相處上不會有太大壓力」「呂顧問目前以自己的診所為主，幾乎不會來醫院；平常對於養身也很有想法」。→ ⭐ 這是一個壓力較小的關卡，可以主動把眼周解剖講深、講滿。
