大面積顏面燒傷後無法閉眼的重建（Post-burn cicatricial ectropion & facial resurfacing）

顱顏與顏面外傷 · 🟠

一句話定位：這是急症，不能等疤痕成熟——角膜暴露會走向 keratopathy → ulcer → 穿孔 → 失明；過度矯正 30–50%，最好的供皮區要留到最後一次手術。

核心模範答案

「燒傷後的 ectropion 造成無法閉眼，我把它當成急症處理，不能等疤痕成熟——因為角膜暴露會依序走向 exposure keratopathy → corneal ulcer → 穿孔 → 失明，而且是不可逆的。

【第一步：保護角膜、同時會診眼科】 大量人工淚液與眼藥膏、moisture chamber，必要時先做暫時性 tarsorrhaphy 把眼睛保住。

【第二步：判斷病理層次】 〔課本・Neligan Vol.4 燒傷章〕乾熱造成的燒傷極少直接傷到 levator 或 tarsus 這些深部結構，所以絕大多數的燒傷性 ectropion 都是「cicatricial」——問題出在前板（anterior lamella）的皮膚不足。因此絕大多數只需要「疤痕鬆解＋植皮」，不需要複雜的瞼板重建。 這是我判斷的第一個分岔點。

【第三步：手術原則】

  • 1. 先鬆較嚴重的那一側；若有角膜暴露的疑慮，優先鬆上眼瞼——因為閉眼主要靠上眼瞼。
  • 2. 鬆解要徹底：平行於 lid margin 切開，一路鬆到眼瞼可以被動地過度矯正；術中用 frost suture 或暫時 tarsorrhaphy 維持張力。
  • 3. 移植材料選全層皮（FTSG）：上眼瞼取對側或同側上眼瞼皮、耳後皮（最薄）；下眼瞼取耳後、鎖骨上、上臂內側。
  • 4. ⭐ 一定要過度矯正 30% 到 50%，因為全層皮仍會二次收縮。
  • 5. 若 snap-back test 或 distraction test 顯示水平方向鬆弛，要同時做 lateral canthopexy／canthoplasty 或 tarsal strip，否則單純植皮還是會掉下來。
  • 6. 術後長期副木、壓力治療、矽膠片。

【第四步：供區策略】 〔課本〕顏面重建有五個 blush area——顏面本身、耳後、頸部、鎖骨上、上臂內側——顏色最相配，但數量有限，要省著用，最好的供區要留到最後一次手術。 大面積顏面燒傷的病人往往要開很多次，第一次手術就把最好的皮用光，是很常見的錯誤。」

追問樹

  • 考官問「為什麼是 FTSG 不是 STSG？」 → 你答：顏面二期的局部次單位重建（眼瞼、鼻、口周）一律優先 FTG，因為二次收縮少、色澤與質地自然〔課本・Neligan Vol.4 Ch.20 顏面重建總則〕；⚠ 但急性期／全臉／大面積、供皮區有限時，標準做法是厚 STSG 以 sheet（不網狀）依美學單位鋪設。
  • 考官問「什麼時候手術？要等疤痕成熟嗎？」 → 你答：原則等疤痕成熟約 1 年，但功能性問題是例外——小口症（microstomia）、眼瞼外翻（ectropion）、頸部攣縮這三者必須立即手術。
  • 考官問「如果連 FTSG 都不夠、或底下是骨頭不能植皮？」 → 你答：走向 local flap → nasolabial flap（high pivot point，設在靠近 medial canthus 的上方）；後層不足則用 hard palate mucoperiosteal graft 或 buccal mucosa。
  • 考官問「病人不但不能閉眼，也不能笑？」 → 你答：那就要同時考慮 facial nerve palsy（見〈外傷後顏面神經麻痺〉一則），但眼睛保護永遠優先。
  • 考官問「極端病例還有什麼選項？」 → 你答：顏面異體複合組織移植（facial VCA）——但我會把它放在重建階梯的最末端，且必須建立在完整的免疫抑制與長期追蹤團隊之上。
