尺神經損傷的高位 vs 低位鑑別（High versus low ulnar nerve injury）

手外科與周邊神經 · 🔴

一句話定位：全手冊跨年跨考官排名第一的題目，而唯一的鑑別鑰匙就是「手背尺側的感覺」。

核心模範答案

「報告老師，尺神經損傷我一定先回答一個問題：這是高位還是低位。

【判準——最簡單、最快的單一鑑別點】 檢查無名指與小指「背側」的皮膚感覺。 機轉：ulnar nerve 的 dorsal cutaneous branch 在腕橫紋近端約 5–8 公分處分出（文獻範圍到 10 公分），走在 FCU 的深面繞到手的背側，支配手背尺側半與環指、小指背側的皮膚。它「不」進入 Guyon's canal。

  • 背側感覺有缺損 → 病灶在此分支的近端 → high lesion（cubital tunnel、前臂 ulnar nerve injury）。
  • 背側感覺完全正常、只有掌側麻 → low lesion（Guyon's canal）。

同理，palmar cutaneous branch 也在腕部近端分出，所以 Guyon's canal 的病灶也不影響 hypothenar 掌面的感覺。

【四項對照】

項目 高位（cubital tunnel 或更近端） 低位（Guyon's canal／腕部）
手背尺側感覺 喪失 ← 最快的鑑別點 正常
FCU 與環指、小指的 FDP 無力（固定 PIP 測 DIP 屈曲） 正常
Clawing 的嚴重度 ⚠ 較不明顯 ⚠ 較明顯
掌側尺側一隻半手指感覺 喪失 喪失（superficial branch 受影響時）

【⭐ Ulnar paradox（尺神經矛盾現象）——這一段是本題的加分句】 位置「越高」的損傷，claw 反而「越不明顯」。原因是——高位損傷連環指、小指的 FDP 都一併癱瘓，IP 缺乏屈曲的力量，反而彎不起來；低位損傷時 FDP 完好，IP 的屈曲力量還在，claw 就特別明顯。 臨床意義：神經恢復時 FDP 會先長回來，病人的 claw 反而「看起來變嚴重」——這不是惡化，是恢復的過程。」

追問樹

  • 考官問「dorsal cutaneous branch 到底在幾公分處分出？」 → 「大約腕橫紋近端 5 到 10 公分都有記載；重點不是那個數字，而是它在 Guyon's canal 之前就分出去了，所以腕部的損傷不會影響手背尺側的感覺——這就是我用來區分高低位的依據。」〔課本多寫 5–8 cm；〔考生回憶‧邱浩遠關〕記 8–10 cm，兩版並列。〕
  • 考官問「還要做哪些檢查？」 → NCV/EMG（定位病灶、看 fibrillation potential 有無 denervation、看 nascent MUP 有無再生；外傷後至少等 3–4 週才有意義，因為要等 Wallerian degeneration）；高解析度超音波／MR neurography 找神經瘤或外在壓迫；X 光看肘部畸形、cubitus valgus、hook of hamate fracture。
  • 考官問「病史要問什麼？」 → 受傷時間與機轉、症狀是一開始就有還是後來才出現（原發損傷 vs 續發壓迫或神經瘤）、進行性惡化還是穩定、慣用手、職業、有無頸椎病變或糖尿病（double crush 與周邊神經病變）。
  • 考官問「PE 要怎麼排？」 → 四層：①望診（第一背側骨間肌與 hypothenar 萎縮、interosseous guttering）②感覺（掌側尺側一隻半＋手背尺側）③運動與特殊徵象（六大 sign ＋ Bouvier）④關節（PIP 有無已固定的屈曲攣縮——這會直接改變治療計畫）。

爪形手的病理機轉與「為什麼修補後三個月才出現」（Claw hand pathomechanics）

手外科與周邊神經 · 🔴

一句話定位：林有德 2025 年整關最重的一題，考點不在 claw 本身，而在「三個月」這個時間點。

核心模範答案

「報告老師，我分兩層解釋——第一層是 claw hand 本身的機轉，第二層是為什麼在術後三個月才出現。

【第一層｜claw hand 的機轉】 正常的內在肌——lumbricals 加 interossei——因為走在 MCP 關節的「掌側」、卻走在 IP 關節的「背側」（經 lateral band 併入 extensor mechanism），所以它們同時做兩件事：屈曲 MCP、伸直 IP。 尺神經麻痺後，第三、第四 lumbrical 與全部 interossei 失去功能：對環指與小指而言，MCP 的屈曲力量沒有了、IP 的伸直力量也沒有了。 於是——沒有被拮抗的 EDC 在 MCP 造成 hyperextension；沒有被拮抗的 FDS 與 FDP 在 IP 造成 flexion。這就是 intrinsic minus hand ＝ claw hand（Duchenne sign）。 ⚠ 這裡有一個惡性循環一定要講：MCP 一旦過度伸直，extensor 的力量就被「消耗」在 MCP 這個關節上、傳不到遠端的 IP，於是 IP 更伸不直，變形更嚴重。 食指與中指不會 claw，因為第一、第二 lumbrical 仍由 median nerve 支配。

【第二層｜為什麼是三個月——這才是真正的考點】 神經修補後軸突再生的速度大約每天 1 毫米、也就是一個月一英吋。從前臂的修補處到手部內在肌距離約 20 到 30 公分，所以再生要走 8 到 12 個月才會到達內在肌。 三個月的時候，內在肌其實還完全處在去神經狀態、而且已經開始萎縮；但外在肌——EDC、FDS、FDP 的橈側兩條——本來就沒受損或已先恢復。內在肌與外在肌的力量失衡，變形就顯現出來。 另一個實務因素是：術後前幾週手被副木固定、關節不太活動；三個月時副木早已拆除、病人開始積極使用手部，這時變形才被注意到。

【結論】 術後三個月出現 claw hand，不代表手術失敗，而是「內在肌的再神經化還沒到達」的必然現象。這時最重要的處置是——用 anti-claw splint 阻擋 MCP 過度伸直、並積極做被動運動，預防 PIP 形成固定的屈曲攣縮。因為一旦 PIP 攣縮固定，後面所有的神經或肌腱重建都會失敗。」

追問樹

  • 考官問「那 lumbrical 的功能怎麼記？」 → 「用解剖位置記：它走在 MCP 的掌側、卻走在 IP 的背側，所以同時是 MCP 的屈肌、IP 的伸肌。這一條就解釋了整個 claw hand 的機轉。」
  • 考官問「病人問你會不會好？」 → 加分句：「『現在的變形是暫時的，但如果關節僵掉了，就會變成永久的。』所以復健的重點不是等神經長回來，而是在等的這一年裡，把關節的活動度完整地保存下來。」
  • 考官問「四隻手指都 claw 呢？」 → 要立刻升級診斷：「只有 ulnar nerve injury 時，claw 應該只出現在環指與小指，因為第 1、2 lumbrical 由 median nerve 支配。四指全 claw、又有 thenar atrophy → 是 ulnar 合併 median nerve 損傷。」〔李經維 107 三號題的核心〕
  • 考官問「還有什麼徵象可以佐證？」 → ① 第一背側骨間肌萎縮（第一指蹼背側凹陷，ulnar palsy 最早最明顯的視覺徵象）② hypothenar eminence 扁平 ③ interosseous guttering ④ thenar hypotrophy。

尺神經六大徵象與其機轉（Six signs of ulnar nerve palsy）

手外科與周邊神經 · 🔴

一句話定位：只講名字必被追問機轉——這一題的評分點是「能不能邊做邊講為什麼」。

核心模範答案

「報告老師，尺神經的徵象我一邊做一邊講機轉。

徵象 表現 機轉（⚠ 一定要講）
Froment's sign 用拇指與食指側面捏紙時，拇指 IP 關節屈曲 adductor pollicis 與第一背側骨間肌無力 → 病人改用 median／AIN 支配的 FPL 代償，於是 IP 彎起來
Jeanne's sign 同一動作時拇指 MCP 過度伸直 adductor 無力使 MCP 不穩，EPL 代償造成 MCP hyperextension；常與 Froment 併存
Wartenberg's sign 小指持續外展、無法與環指併攏 第三 palmar interosseous（內收小指）無力，而 radial nerve 支配的 EDM（有外展作用）失去對抗
Duchenne's sign 環指與小指 MCP 過度伸直 ＋ IP 屈曲（＝ clawing 本身） 第 3、4 lumbrical 與 interossei 失能 → EDC 在 MCP 無拮抗、FDS/FDP 在 IP 無拮抗
Masse's sign 掌弓（metacarpal arch）變平、小指掌骨無法下沉 opponens digiti minimi 與 hypothenar 群無力／萎縮
Pitres–Testut sign 無法把中指向兩側偏移、做不出「金字塔／牛角」手勢 interossei（手指外展與內收）無力

另外兩個一定要一起講的：

  • Bouvier maneuver：擋住 MCP hyperextension 後，IP 能主動伸直＝simple claw；不能＝complex claw——它決定 tendon transfer 要不要插到 lateral band。
  • Card test（Egawa test）：兩指之間夾紙、或手指主動外展內收，快速篩檢 interossei 力量。

⭐ 最後我會補一句指標肌：第一背側骨間肌是最容易目視、也最不會被其他神經代償的指標肌〔考生回憶‧108 新光關考官明說：「大家都有管到的功能很難區分，最好測 first dorsal interosseous」〕。」

追問樹

  • 考官問「Wartenberg's sign 是哪一條神經？」 → ulnar。⚠ 但講法要有次序：「這個表現最符合 interosseous muscle 的無力，我第一個懷疑 ulnar nerve；但若合併 thenar 萎縮與拇指對掌困難，就要一併考慮 median nerve 的合併損傷。」
  • 考官問「Froment 為什麼會 IP 屈曲？」 → adductor pollicis 無力 → FPL 代償；FPL 由 AIN（median）支配，所以尺神經壞掉時它還在。
  • 考官問「怎麼矯正這些徵象？」 → Froment（拇指內收無力）→ ECRB ＋ 肌腱移植轉到 adductor pollicis；Wartenberg（小指持續外展）→ EDM 尺側半條轉到小指 A1/A2 pulley 或縫到橈側 collateral ligament；食指外展無力 → EIP 轉到第一背側骨間肌。

Bouvier test 與 simple vs complicated claw（Bouvier maneuver）

手外科與周邊神經 · 🔴

一句話定位：它不是診斷工具，是「術式分流器」——決定 transfer 插不插到 lateral band。

核心模範答案

「報告老師，在做任何 tendon transfer 之前，我一定先做 Bouvier maneuver 來分類。

【做法】 檢查者擋住 MCP 的過度伸直（把 MCP 被動屈曲固定住），然後請病人主動伸直 PIP 與 DIP。

【判讀與其臨床決策——這才是考點】

  • 能主動伸直 → 「simple claw／supple claw」（Bouvier 陽性）：代表 extensor mechanism 本身是完好的，變形純粹來自 MCP 失去屈曲的拮抗。

→ 我的 transfer 只需要「在 MCP 產生屈曲」就好——可以插到 A1 或 A2 pulley、或插到 proximal phalanx，「不需要」插到 lateral band。 → 可以走 static procedure（Zancolli volar plate capsulodesis、MCP volar tenodesis、bone block） 或 Zancolli lasso。

  • 擋住 MCP 之後 IP 仍伸不直 → 「complicated / complex claw」（Bouvier 陰性）：代表 extensor mechanism 已經失效或有續發攣縮。

→ 必須把 transfer 一路插到 lateral band，才能同時提供 IP 的伸直力量 → dynamic procedure（modified Stiles–Bunnell、Brand）。

【背後的原理】 擋住 MCP 等於人工替代了 intrinsic 在 MCP 的屈曲作用；此時 extensor 的力量不再被「消耗」在 MCP 這個關節上，就能傳遞到遠端的 IP。所以病人能不能伸直 IP，測的其實是「extensor mechanism 的完整性」。」

追問樹

  • 考官問「Simple claw 的 transfer 要插在哪裡？」 → 〔考生回憶‧104 邱浩遠同題〕「Bouvier 陽性代表只要在 MCP 產生屈曲即可，所以肌腱插到 A1／A2 pulley 或 proximal phalanx 就夠，不必插到 lateral band。」
  • 考官問「怎麼確定它是 claw finger 而不是別的？」 → 〔考生回憶‧邱浩遠版〕「把 MCP 從過度伸直的位置壓平固定住，PIP 與 DIP 就自然伸直了 → 證明是 lumbrical weakness。」
  • 考官問「Bouvier 陰性一定是 extensor 壞掉嗎？」 → 要先排除 PIP 已形成固定的屈曲攣縮——攣縮的關節是 tendon transfer 的絕對禁忌，必須先復健把被動活動度做回來，再談手術。

爪形手的四層治療階梯與動態肌腱轉移（Treatment ladder for claw hand）

手外科與周邊神經 · 🔴

一句話定位：一開口就講 tendon transfer 是本題最大的地雷——順序永遠是保守 → 神經 → 神經轉移 → 肌腱轉移。

核心模範答案

「報告老師，我分四層。

【第一層｜保守治療——永遠不能跳過的一層】 anti-claw splint（lumbrical bar／figure-of-eight splint）：作用是阻擋 MCP 過度伸直，讓 extensor 的力量能傳遞到 IP，同時也是功能性輔具。 ⚠ 最重要的目的是「預防 PIP 形成固定的屈曲攣縮」——因為一旦 PIP 攣縮，後面所有的神經或肌腱重建都不會成功。加上積極的被動運動與 hand therapy。

【第二層｜神經層次】 壓迫性病變 → in situ decompression 或 anterior transposition。 斷裂 → 無張力的 primary epineurial repair；有缺損 → sural nerve graft；缺損 3 公分以內也可考慮 conduit 或處理過的 nerve allograft。

【第三層｜神經轉移（nerve transfer）】——適用於損傷位置太近端、軸突來不及在終板退化前抵達者。 AIN 的末端（到 pronator quadratus 的分支）→ ulnar nerve 的 deep motor branch，做 supercharge end-to-side。時機是受傷後 6 到 12 個月內、越早越好。

【第四層｜肌腱轉移（tendon transfer）】——適用於超過 12 到 18 個月、內在肌已不可逆萎縮者。先做 Bouvier maneuver 分類。

【動態 transfer 的 donor——最常用的是 FDS】

  • 1. Zancolli lasso procedure（最標準）：把 FDS 從 A1 pulley 的近端拉出，繞過 A1 pulley 後折回縫到自己身上，形成套索。收縮時拉緊 A1 pulley、直接在 MCP 產生屈曲。優點：手術簡單、不需肌腱移植、不必進到手指裡。適用 Bouvier 陽性的 simple claw。
  • 2. Modified Stiles–Bunnell：取中指或環指的 FDS，縱向分成數束，經 lumbrical canal 插到環指與小指的「橈側 lateral band」。同時提供 MCP 屈曲與 IP 伸直 → 適用 Bouvier 陰性的 complex claw。⚠ FDS 取太多會造成 donor 手指 swan-neck deformity，所以要保留 FDS 在中節指骨的部分止點。
  • 3. Brand transfer（EF4T／EE4T）：ECRL 或 ECRB ＋ 肌腱移植，經 intermetacarpal space 或背側繞到 lateral band。

【靜態做法】：Zancolli volar plate capsulodesis 或 MCP volar tenodesis——單純阻擋 MCP 過度伸直，適用 Bouvier 陽性、活動需求不高者。

【常一起問的另外三個 transfer】

  • 矯正 Froment's sign（拇指內收無力）→ ECRB ＋ 肌腱移植 → adductor pollicis。
  • 矯正 Wartenberg's sign（小指持續外展）→ EDM 尺側半條 → 小指 A1／A2 pulley，或縫到橈側 collateral ligament。
  • 矯正食指外展無力 → EIP → 第一背側骨間肌。
  • 高位損傷造成的環指、小指 FDP 無力 → 側縫到中指的 FDP（side-to-side）。」

追問樹

  • 考官問「做 tendon transfer 之前要確認什麼？」 → 七大原則：「① 傷口穩定、關節柔軟、無攣縮 ② donor 肌力至少 M4–M5（transfer 後一定掉一級）③ amplitude 匹配——手腕約 25–33 mm、伸指肌約 50 mm、屈指肌約 70 mm（記憶：3-5-7）④ 直線牽引 ⑤ 一條肌腱只做一個功能 ⑥ 盡量選協同（synergistic）肌肉 ⑦ donor 必須可犧牲。」
  • 考官問「三前提是什麼？」（陳理維版）→ 關節被動活動度完整、軟組織床穩定無疤痕、donor 肌力至少 MRC 4 級以上且功能可犧牲。

Cubital tunnel 與 Guyon's canal（Cubital tunnel versus Guyon's canal syndrome）

手外科與周邊神經 · 🟠

一句話定位：壓迫點要背得出來、Gross–Gelberman 三區要分得清楚，而治療必須從減壓開始、不是從 nerve transfer 開始。

核心模範答案

「報告老師，我分成解剖、分區、與治療三段。

【Cubital tunnel 的邊界與壓迫點】 邊界：內側為 medial epicondyle、外側為 olecranon、底部為 MCL 的後斜束與關節囊、頂部為 Osborne's ligament（cubital tunnel retinaculum）與 FCU 兩頭之間的腱膜弓。 ⚠ 屈肘時 tunnel 容積減少、內壓上升——所以症狀常在屈肘睡覺時最嚴重。 由近到遠五個壓迫點（必背）：① Arcade of Struthers ② medial intermuscular septum ③ medial epicondyle（cubital tunnel retinaculum／Osborne's ligament）④ FCU 兩頭之間 ⑤ deep flexor–pronator aponeurosis。

【Guyon's canal 的邊界與 Gross–Gelberman 三區】 邊界：橈側為 hook of hamate、尺側為 pisiform；底部為 transverse carpal ligament 與 pisohamate ligament；頂部為 volar（palmar）carpal ligament 與 palmaris brevis。 ⭐ Gross–Gelberman 三區：

  • Zone 1（分叉前）：運動＋感覺都受影響——常因 ganglion 或骨折。
  • Zone 2（deep motor branch）：純運動——hook of hamate fracture、ganglion。
  • Zone 3（superficial sensory branch）：純感覺——ulnar artery thrombosis／hypothenar hammer syndrome。

【治療階梯——⚠ 這是本題的評分關鍵】

  • ① 保守：避免長時間屈肘與肘部壓迫、夜間伸肘副木、活動調整、NSAID，觀察 3 個月。
  • ② in situ simple decompression（neurolysis）。
  • ③ anterior transposition（subcutaneous／intramuscular／submuscular）。
  • ④ medial epicondylectomy。
  • ⑤ 只有在已有明顯肌肉萎縮、去神經時間長時，才加做 supercharge end-to-side 的 AIN → ulnar deep motor branch transfer。

⭐ EBM 更新（加分）：多篇隨機試驗與 Cochrane 統合分析顯示，simple decompression 與 anterior transposition 在 cubital tunnel syndrome 的療效沒有顯著差異，而 simple decompression 併發症較少、手術較單純——所以現在的趨勢傾向 simple decompression，除非有肘關節不穩定、神經半脫位、或先前手術失敗。」

追問樹

  • 考官問「已經有 muscle atrophy 了呢？」 → 〔考生回憶‧陳理維 111 原答〕「anterior transposition ＋ AIN transfer to ulnar（deep motor branch）」。理由要講：已有萎縮代表遠端運動終板正在流失，單靠近端減壓的再生距離太長（1 mm/day，從肘到手內在肌要一年以上），加做 supercharged end-to-side 可以先把終板保住。
  • 考官問「為什麼 hook of hamate 這麼重要？」 → 它是 Guyon's canal 的橈側壁、transverse carpal ligament 的尺側附著點、Kaplan's cardinal line 的尺側終點；hook of hamate fracture（高爾夫、球棒握把）是 ulnar nerve deep motor branch 壓迫的典型原因。
  • 考官問「Zone 3 為什麼會純感覺？」 → 因為 superficial branch 只帶感覺纖維；臨床上常見於 hypothenar hammer syndrome（反覆以掌根敲擊）造成的 ulnar artery thrombosis。

神經轉移總論與 AIN 轉尺神經運動支（Nerve transfer; AIN to ulnar motor branch）

手外科與周邊神經 · 🟠

一句話定位：nerve transfer 存在的唯一理由是「運動終板的時間窗」——講不出這句話，就只是在背術式名字。

核心模範答案

「報告老師，針對 ulnar nerve 的運動功能，標準的 nerve transfer 是——把 AIN 的末端（支配 pronator quadratus 的那一支）轉接到 ulnar nerve 的 deep motor branch。

【技術細節】 手術位置在 Guyon's canal 的近端、大約腕橫紋近端 4 到 6 公分處。先做 internal neurolysis，把 ulnar nerve 的 motor fascicle 與 sensory fascicle 分開——motor fascicle 通常位於背橈側——再把 AIN 的末端接到 motor fascicle 上。 可以 end-to-end，也可以 end-to-side；現在更常用的是 end-to-side，也就是 supercharge end-to-side（SETS）。

【SETS 的概念——「babysitter」】 在近端修補的軸突還沒長到手部之前，先由 AIN 提供軸突去「養」運動終板，讓終板不要在等待期間退化死掉。等近端的軸突終於抵達，終板還是活的，就還能被重新接管。

【為什麼 donor 選 AIN——三個理由】 ① 距離：它的末端支就在腕部附近，長度足夠、位置就在受贈的 ulnar nerve 旁邊。 ② 犧牲代價極小：犧牲 PQ 之後，前臂旋前的主力 pronator teres 仍然完好，功能損失可忽略。 ③ 軸突數目匹配：AIN 到 PQ 的分支約 900–1000 條軸突，ulnar nerve 的 deep motor branch 約 1000–1200 條，兩者非常接近。

【時機】 受傷後 6 到 12 個月內、越早越好；超過 12 到 18 個月，運動終板已不可逆退化，任何神經手術都無效，只能做肌腱轉移。

【感覺的部分也可以做】 把 median nerve 的第三 common digital nerve 用 end-to-side 接到 ulnar nerve 的 sensory branch，恢復小指與環指尺側的保護性感覺。

【nerve transfer 的五大原則（總論）】

  • ① donor 要純運動、且功能可犧牲；② 越靠近 target 越好（縮短再生距離）；③ donor 與 recipient 有協同性（synergy）有助再學習；④ 時間窗：運動終板約 12–18 個月不可逆；⑤ end-to-side「supercharge」可用來保住終板。」

追問樹

  • 考官問「AIN 支配的最末端肌肉是哪一條？」 → Pronator quadratus（PQ）。⚠ 千萬不要只答三個字就停，立刻補三個臨床意義：「① 它是 AIN 最末端分支，所以 AIN syndrome 的 EMG 上 PQ 的異常最敏感 ② 正因為在最末端、位置就在腕部，所以是 nerve transfer 最理想的 donor ③ 犧牲代價極小。」
  • 考官問「其他常考的 nerve transfer 組合？」 → Oberlin transfer（尺神經中支配 FCU 的一至兩束 fascicle → musculocutaneous nerve 的 biceps branch，重建屈肘）；double Oberlin（再加 median nerve 一束到 brachialis branch）；spinal accessory → suprascapular（肩外展外旋）；intercostal nerves → musculocutaneous；contralateral C7；masseteric → facial；FCR/FDS 的 median 分支 → PIN／ECRB 分支。末期則做 free functioning muscle transfer（gracilis）。
  • 考官問「BPI 要怎麼分？」 → preganglionic vs postganglionic 最關鍵。節前的線索：Horner syndrome（T1 根撕脫）、翼狀肩胛（long thoracic）、菱形肌無力（dorsal scapular）、橫膈麻痺（phrenic）、劇烈去傳入疼痛、CT/MR myelography 上的 pseudomeningocele、⚠ SNAP 正常但臨床完全沒有感覺（背根神經節仍與周邊軸突相連）。節前無法直接修補，只能做 nerve transfer。

周邊神經損傷分級、再生與修補原則（Peripheral nerve injury, regeneration and repair）

手外科與周邊神經 · 🔴

一句話定位：這是整卷手外科的地基——再生速度決定時間窗，時間窗決定你選 repair、graft、nerve transfer 還是 tendon transfer。

核心模範答案

「報告老師，我分成分級、再生、追蹤、與修補原則四段。

【一、分級（Seddon／Sunderland）】〔課本〕

  • Neurapraxia（Sunderland I）：局部去髓鞘、軸突連續性完整，無 Wallerian degeneration；數天到數週自行完全恢復。
  • Axonotmesis（Sunderland II–IV）：軸突斷裂但支持結構部分保留，遠端發生 Wallerian degeneration，依 1 mm/day 沿原管路再生；Sunderland III（endoneurium 破壞）、IV（perineurium 破壞）恢復不完全，IV 常需手術。
  • Neurotmesis（Sunderland V）：整條神經完全斷裂，不手術不會恢復。
  • Sunderland VI（Mackinnon）：混合型，同一條神經不同束處於不同等級。

【二、再生速度】 標準答案是每天 1 毫米，約等於每個月 1 英吋（2.5 公分）。 但實際要加上兩個修正： ① 潛伏期（latency period）——遠端 Wallerian degeneration 需 1–2 週，軸突跨過吻合處本身需 2–4 週。臨床估算公式：約 1 個月潛伏期 ＋ 距離 ÷ 1 mm/day。 ② 位置與年齡——越近端越快（近端可到 2–3 mm/day），越遠端越慢；年輕人比老人快；單純壓迫性病變減壓後恢復可遠快於 1 mm/day，因為那是去髓鞘的問題而不是軸突斷裂。

【三、怎麼追蹤再生】 ① Tinel sign 的推進——叩擊點每個月往遠端前進約 1 英吋。⚠ Tinel 停在原地不再前進，代表修補失敗或形成神經瘤，要考慮再次手術。 ② EMG——nascent motor unit potential 的出現通常比臨床可見的肌肉收縮早 2–3 個月；外傷後至少等 3–4 週做才有意義。 ③ 恢復順序永遠是由近端到遠端。

【四、修補原則】

  • 時機：乾淨的銳器傷 → primary repair（越早越好）；污染、壓砸、撕脫 → 先清創、tag 神經、延遲一期或二期修補（約 3 週後，此時神經斷端界線清楚、epineurium 較厚好縫）。
  • 技術：放大鏡或顯微鏡下、epineurial repair 為主、束對束對位（用血管走向與束型對位）、最少的縫線、無張力。
  • ⭐ Tension-free 是鐵律：張力會造成缺血與疤痕，在張力下做的吻合幾乎注定失敗。
  • 有缺損時：自體 nerve graft（sural nerve 為主，前臂內側皮神經、great auricular nerve 亦可）；缺損 3 公分以內可考慮 conduit（導管）或處理過的 nerve allograft；缺損大或距離太遠 → nerve transfer。
  • ⭐ 決策公式：用「距離 ÷ 1 mm/day」去預測軸突來不來得及在終板死掉（12–18 個月）之前抵達。來不及，就必須改用 nerve transfer，把新的神經源搬到靠近終板的地方——這就是 nerve transfer 存在的理由。」

追問樹

  • 考官問「有一點 under tension，是不是一定要 nerve graft？」 → ⚠ 這是經典衝突題，見下方裁決。標準講法：「原則是 tension-free repair，張力大就要用 nerve graft。不過如果張力可以用姿勢位克服，我仍然偏好 primary repair，因為只有一個 coaptation site、再生結果比較好——術後用副木固定在屈腕位，再每次十度慢慢伸直。」
  • 考官問「要跟病人解釋什麼？」 → ⚠ 術前一定要說明可能需要取 sural nerve，小腿會多一道傷口、且該區域會永久麻木〔考生回憶‧邱浩遠關特別強調〕。

正中神經的支配清單（Median nerve innervation）

手外科與周邊神經 · 🔴

一句話定位：純背誦題，沒有推理空間，會就是會——要練到 40 秒內從近端流暢排到遠端。

核心模範答案

「報告老師，我從近端排到遠端。

【前臂——median nerve 本幹依序支配四條】 Pronator teres → Flexor carpi radialis → Palmaris longus → Flexor digitorum superficialis（全部四條）。

【接著分出 anterior interosseous nerve（AIN）——純運動支，支配三條】 Flexor pollicis longus → Flexor digitorum profundus 的食指與中指 → Pronator quadratus。 ⭐ PQ 是 AIN 最末端的肌肉。

【感覺】 ① Palmar cutaneous branch 在腕隧道的「近端」就分出、而且不進入隧道，支配大魚際的皮膚——這就是為什麼腕隧道症候群的病人手掌基部感覺是正常的，也是它與高位 median nerve 損傷最關鍵的鑑別點。 ② Common digital nerve 支配橈側三隻半手指的掌側，以及食指、中指遠節的背側。」

手內在肌完整清單與神經支配（Hand intrinsic muscles）

手外科與周邊神經 · 🔴

一句話定位：四群、19–20 條——要一口氣講完，而且神經支配的分法才是真正的考點。

核心模範答案

「報告老師，手的內在肌一共分四群：

【第一群｜大魚際（thenar）四條】 Abductor pollicis brevis、Flexor pollicis brevis、Opponens pollicis、Adductor pollicis。

【第四群｜骨間肌（interossei）七條】 背側四條（dorsal interossei）＝ DAB（Dorsal ABduct），負責手指外展；掌側三條（palmar interossei）＝ PAD（Palmar ADduct），負責手指內收。

【合計 19 到 20 條。】

【⭐ 神經支配的分法才是關鍵】 ulnar nerve 支配絕大多數的內在肌；median nerve 只支配五個半——也就是 LOAF：第一、第二 lumbrical、opponens pollicis、abductor pollicis brevis，以及 flexor pollicis brevis 的「淺頭」。FPB 的深頭是 ulnar 支配的。 〔考生回憶‧邱浩遠關的說法〕臨床上常說 ulnar nerve 損傷會造成「14.5 條」內在肌無力——那個 0.5 就是 FPB 只有一半（深頭）受 ulnar 支配。」

追問樹

  • 考官問「安全位副木的角度？」 → wrist 20–30° 伸直、MCP 70–90° 屈曲、IP 完全伸直、拇指外展對掌位。理由：MCP 的 collateral ligament 在屈曲位時被拉到最長，volar plate 在 IP 伸直位時最長；把韌帶固定在最長的位置，才不會在攣縮後失去活動度。

腕隧道症候群與高位正中神經／AIN 症候群的鑑別（Carpal tunnel versus AIN and pronator syndrome）

拇指對掌的立體性與對掌重建（Opposition and opponensplasty）

手外科與周邊神經 · 🟠

一句話定位：對掌不是「拇指碰到小指」，而是「掌心可以放得下一顆雞蛋」的立體結構——這是李經維 107 年的正解。

核心模範答案

「報告老師，對掌（opposition）是 abduction → flexion → pronation 三個動作的組合，所以正常對掌時拇指與小指之間是一個『立體』的空間——掌心可以放得下一顆雞蛋。

【怎麼判斷不正常】 如果病人的拇指是貼著手掌心平移過去的，代表缺少 palmar abduction 與 pronation，形不成那個立體結構——這代表 thenar 的 opponens pollicis 與 abductor pollicis brevis 麻痺，也就是 median nerve（recurrent motor branch）的損傷。

【⚠ 兩個必須排除的錯誤答案】

  • AIN syndrome 不會造成對掌障礙——AIN 是純運動神經，支配 FPL、食指與中指的 FDP、PQ，不支配 thenar。
  • 單獨 FPB 麻痺也不會造成無法對掌——FPB 的深頭由 ulnar、淺頭由 median 支配，但對掌的主角是 opponens pollicis 與 APB。

【對掌重建（opponensplasty）——⭐ 記法：6 × 6 × 6，六個 donor、六個 pivot point、六個 insertion】 Donor：FDS（中指或環指）、EIP（Tubiana）、PL（Camitz）、ADM（Huber）、ECU（Phalen–Miller）、ECRL、EPL。 Pivot point（滑車）：pisiform（Bunnell）、FCU 止點附近、穿過或繞過 transverse carpal ligament（Thompson）、Guyon's canal、掌腱膜、FCR。 Insertion：APB 的止點（最常用）、拇指近節指骨基部、EPL 的肌腱（可同時提供伸直的成分）。

【⭐ 選 donor 的原則】 FDS 力量最好，但可能造成 donor 手指 swan neck；EIP 犧牲代價最小；PL（Camitz）最簡單，常在 CTS 手術時順便做，但它主要提供的是「外展」而非真正的「對掌」。」

橈神經麻痺、垂腕與 PIN 症候群（Radial nerve palsy, drop wrist, PIN syndrome）

手外科與周邊神經 · 🔴

一句話定位：鑑別的一刀切是「手腕能不能伸直」與「手背橈側有沒有麻」——兩個都要講才算答完。

核心模範答案

「報告老師，我先做鑑別，再講時序，最後才講重建。

【一、鑑別——兩個軸】

  • High radial nerve palsy（在 supinator 近端，經典情境是 humeral shaft 或 distal humerus fracture s/p ORIF）：drop wrist——手腕伸不起來，手指與拇指也伸不起來，且合併手背橈側（第一指蹼背側）的感覺喪失。

  • ⭐ 第三個要一併提的是 Wartenberg syndrome（superficial radial nerve 的壓迫）：純感覺、手背橈側麻，沒有任何運動障礙。

  • 有恢復跡象 → 繼續觀察 ＋ dynamic extension splint（outrigger）維持關節活動度。
  • 開放性傷口、骨折復位「之後」才出現的麻痺、或觀察無進展 → 手術探查、neurolysis、primary repair 或 nerve graft。

【三、重建的三段時序】 ① 早期（一年內、終板還活著）→ 先想 distal nerve transfer〔考生回憶‧陳理維 109/110 的補充：「才一年的時間，應該可以先考慮 nerve transfer」〕，例如 median nerve 到 FDS 或 FCR 的分支 → PIN／ECRB 的分支。 ② 超過 12–18 個月、或距離太遠 → tendon transfer。 ③ 動力肌都已耗盡 → free functioning muscle transfer（free gracilis）。

【四、等待期間的處置】 dynamic extension splint（outrigger）——它的目的不是治療，是維持關節被動活動度，因為攣縮的關節是 tendon transfer 的絕對禁忌。」

核心模範答案

「報告老師，橈神經麻痺的經典 tendon transfer 有三套，要恢復的永遠是三個功能：伸腕、伸指、伸拇。

外展／APL・EPB — — FCR → APL + EPB

【我採 FCR transfer 這一組，理由要講兩層】 ① 為什麼選 FCR 而不用 FCU：FCU 是最強的腕屈肌，也是尺側偏移（ulnar deviation）與 dart-thrower's motion 的穩定者，犧牲它會失去腕部平衡。保留 FCU、改用 FCR 較符合現代觀念。 ② 為什麼選 ECRB 而不用 ECRL：ECRB 的止點靠中線，產生的是「純伸腕」而不是橈偏。

【Boyes 的優缺點——⚠ 名字不可錯置】 ⭐「Boyes」專指 superficialis (FDS) transfer，不是 FCU／FCR 那一組。 優點：可以做出「獨立的」拇指與食指伸展，力量最完整。 缺點：要犧牲兩條 FDS，有握力下降與 swan neck 的風險，而且要經過 interosseous membrane 的窗口。 ⚠ 中指與環指不要背反：中指（long）的 FDS 走「四指總伸」的 EDC；環指（ring）的 FDS 走「獨立的食指與拇指伸展」的 EIP ＋ EPL。

【⚠ 時序上的鐵律】 若傷後未滿一年，先提 distal nerve transfer，再談 tendon transfer。」

追問樹

  • 考官問「tendon transfer 的 indication 是什麼？」 → 三大類：① Neurologic deficit（脊髓損傷造成健康肌肉癱瘓——目前最常見的適應症；腦性麻痺／小兒麻痺已不再是最常見；神經直接修復後未恢復、神經轉移失敗、肌肉已壞死）；② Loss of muscle–tendon unit（類風濕造成的肌腱斷裂、外傷性缺損）；③ Spastic disorders（頭部外傷、頸髓損傷、腦血管疾病）——⚠ 痙攣性病人轉位後的單元也沒有正常神經控制，預後不可預期，常改用 arthrodesis 來改善平衡。
  • 考官問「早期就做 transfer 有什麼好處？」 → 五個：① 當作 internal splint 預防攣縮 ② 在神經再生期間先改善手功能 ③ 增加再生後肌肉的力量 ④ 替代無法恢復的肌肉 ⑤ 增加手的使用頻率、刺激感覺再教育。
  • 考官問「PT → ECRB 的張力怎麼調？」 → 在 wrist 中立到輕度伸直位縫合，術中用 tenodesis effect 檢查：被動屈腕時手指應自然伸直、被動伸腕時手指應自然屈曲。

肌腱轉移的六大原則與三前提（Principles of tendon transfer）

手外科與周邊神經 · 🟠

一句話定位：這是所有 transfer 題的共同前綴，講出來會讓考官知道你不是在背術式。

核心模範答案

「報告老師，我做任何 tendon transfer 之前都會先確認以下條件。

【三前提（先講這個，最精煉）】 ① 關節被動活動度完整（攣縮的關節是絕對禁忌）② 軟組織床穩定、無疤痕、無水腫 ③ donor 肌力至少 MRC 4 級以上、且功能可犧牲。

【六大原則（展開版）】 ① 關節被動活動度必須完整——先復健、再手術。 ② 組織條件良好——無疤痕、無水腫、感覺尚可。 ③ 足夠的肌力——至少 MRC grade 4，因為轉位後一定會掉一級。 ④ 足夠的 excursion（振幅）——⭐ 記憶「3-5-7」：手腕屈伸肌約 33 mm、伸指肌約 50 mm、屈指肌約 70 mm。（另有教科書把手腕寫成 25–33 mm，範圍相容。） ⑤ 一條肌腱只做一個功能（one tendon, one function）。 ⑥ 直線的牽引方向、協同動作（synergy——例如腕屈與指伸是協同的）、以及 donor 必須是可犧牲的（expendable）。

【⭐ Timing】 先做軟組織平衡與關節活動度的恢復，再做 transfer。」

追問樹

  • 考官問「為什麼要選協同肌？」 → 協同動作的肌肉在中樞已有共同的運動程式，轉位後的再學習（re-education）最快、最自然。例如腕屈與指伸是天然協同的，所以 FCR → EDC 的再學習比非協同的組合容易。
  • 考官問「Transfer 的併發症有哪些？」 → ① Quadriga effect：FDP 過度縮短（或被縫死在斷指殘端）→ 因為 FDP 共用一個肌腹，其他手指也無法完全屈曲，握力下降。② Lumbrical-plus finger：FDP 的肌腱移植過長或 FDP 在遠端被切斷 → 屈指時張力不再傳到遠節、反而經 lumbrical 傳到 lateral band，造成「越用力想屈曲、PIP 反而伸直」的矛盾動作。③ Superficialis finger：只有 FDS 完整、FDP 缺失 → DIP 活動受限。④ 取 FDS 過多 → donor 手指 swan neck。
  • 考官問「痙攣性病人也可以做嗎？」 → ⚠ 預後不可預期，因為轉位後的單元同樣沒有正常的神經控制；常改用 arthrodesis 來改善平衡。

內在肌緊縮與其對照組（Intrinsic tightness; Bunnell–Littler test）

手外科與周邊神經 · 🟠

一句話定位：只講 intrinsic tightness 不夠——一定要同時講出 extrinsic extensor tightness 與 ORL tightness 這兩個對照組，才顯得真的懂。

核心模範答案

「報告老師，intrinsic tightness 是指手內在肌（interossei 與 lumbricals）因為外傷、缺血（compartment syndrome）、燒傷、痙攣、或長期不當固定而攣縮纖維化，導致在 MCP 伸直時 PIP 的被動屈曲受到限制。

【檢查 ＝ Bunnell–Littler test（intrinsic tightness test）】 ① 先把 MCP 固定在伸直（甚至過度伸直）的位置——此時 intrinsic 被拉到最長——測量 PIP 的「被動」屈曲角度。 ② 再把 MCP 屈曲——此時 intrinsic 放鬆——再測一次 PIP 的被動屈曲角度。

【判讀】

  • MCP 伸直時 PIP 難彎、MCP 屈曲時 PIP 可以彎更多 → intrinsic tightness（陽性）。
  • 兩個位置都一樣受限 → 是 PIP 關節本身的關節囊攣縮（capsular contracture），不是 intrinsic 的問題。

【⚠ 兩個對照組——一定要一起講】

  • Extrinsic extensor tightness：MCP「屈曲」時 PIP 的被動屈曲受限、MCP 伸直時反而較好——方向與 intrinsic 完全相反。
  • ORL（oblique retinacular ligament）tightness ＝ Haines–Zancolli test／Boutonnière test：PIP 維持伸直時 DIP 的被動屈曲受限；PIP 屈曲時 DIP 可以彎。

【治療】 早期做 intrinsic stretching（MCP 伸直 ＋ IP 屈曲）與副木；晚期做 distal intrinsic release——切除 extensor expansion 的「斜行纖維（oblique fibers of the lateral band）」，保留 central slip 與 transverse fibers。」

追問樹

  • 考官問「Intrinsic plus 是什麼？跟 intrinsic tightness 有什麼關係？」 → ⭐ 要區分兩件事：「Intrinsic-plus deformity」是病態——intrinsic 攣縮造成的固定變形（MCP 屈曲 ＋ IP 伸直），是 swan-neck deformity 的前身；但「intrinsic-plus position」卻是治療用的安全位副木姿勢，因為它讓 MCP 的 collateral ligament 與 IP 的 volar plate 都處在最長的狀態，可以預防攣縮。⭐ 同一個姿勢，一個是病、一個是藥——這是這題的關鍵。
  • 考官問「安全位副木的四個角度？」 → wrist 20–30° 伸直、MCP 70–90° 屈曲、IP 完全伸直、拇指外展對掌位。⚠ 把手固定在「MCP 伸直、IP 屈曲」的舒服姿勢，兩到三週就會造成永久性攣縮。
  • 考官問「為什麼 intrinsic 攣縮會造成 swan neck？」 → intrinsic 經 lateral band 併入 extensor mechanism，攣縮後把 PIP 拉向過度伸直、同時把力量從 DIP 抽走 → PIP hyperextension ＋ DIP flexion。

多指斷指的接合順序：兩派並列（Sequence of repair: digit by digit versus structure by structure）

手外科與周邊神經 · 🔴

一句話定位：這一題沒有標準答案，考的是「你能不能把取捨講成邏輯」——兩派都講、再說明你的選擇，就不會踩到任何一位考官的偏好。

核心模範答案

「報告老師，接的順序有兩派，我兩種都會講，然後說明我的選擇。

【第一派｜功能優先的 digit by digit】 依手指的功能重要性決定先後。〔考生回憶〕成大的做法是 1 → 3 → 4 → 2 → 5，也就是拇指 → 中指 → 環指 → 食指 → 小指。 邏輯：拇指佔全手功能約 40–50%，絕對優先；中指與環指提供 power grip 與掌弓的穩定；食指如果品質不好，反而是可以取捨、甚至拿來做 heterotopic replantation 移到更重要位置的那一根；小指最後。 好處：萬一途中時間不夠、病人狀況變差、或血管品質不佳而必須放棄，被放棄的一定是最不重要的那一根。

【第二派｜structure by structure, not digit by digit】 精神是：同一個構造，四根一次做完，而不是一根做完再做下一根。 好處：大幅縮短總手術時間、縮短總 ischemia time，而且整台刀只需要翻手兩次；同一種操作連續做，可以固定顯微鏡倍率、器械與心智模式。 ⭐ 成大流程（以「手翻最少次」為原則）： ① 一個 tourniquet time 內把四指所有構造找出來、標記好 ② 全部釘骨（必要時 shortening 約 0.5 公分，換取無張力的血管神經吻合）③ 全部 flexor tendon ④ 翻手 ⑤ 全部 extensor tendon ⑥ 顯微接全部 dorsal vein ⑦ 放鬆背側皮膚 ⑧ 翻手 ⑨ 顯微接全部 artery——跨過 crush zone 就毫不猶豫地用 vein graft ⑩ 接全部 nerve ⑪ 關傷口，皮膚不要縫緊，必要時植皮。

【⭐ 我的選擇】 以 structure by structure 為主軸，但在每一個構造之內，仍然按照功能重要性的順序去做。這樣兩個原則就不衝突了。」

優勢指動脈、1A:2V 與 vein graft（Dominant digital artery, 1A:2V, vein graft）

手外科與周邊神經 · 🔴

一句話定位：這是潘信誠關唯一的純記憶題，答不出來直接失分——而 1A:2V 的理由是「靜脈鬱血才是失敗主因」。

核心模範答案

「報告老師，我分三段：優勢動脈的側別、動靜脈的比例、以及什麼時候用 vein graft。

【一、每一隻手指的 dominant digital artery（必背）】

  • 拇指：尺側（ulnar side）dominant
  • 食指：尺側（ulnar side）dominant
  • 中指：兩側相近，但尺側較常見
  • 環指：橈側（radial side）dominant
  • 小指：橈側（radial side）dominant

⭐ 記法（講出來考官會點頭）：邊緣手指的 dominant artery 都「朝向手的中軸」——拇指與食指朝尺側，環指與小指朝橈側，中指居中所以兩側差不多。 ⭐ 生理解釋（加分）：拇指與食指的「橈側」是捏握時的受壓面，優勢動脈長在尺側才不會被反覆壓迫；小指的「尺側」是手放在桌面時的接觸面，所以優勢動脈在橈側。 補充：斷面較 proximal 的拇指，可以直接接 princeps pollicis artery。

【二、接幾條動脈、幾條靜脈】 〔課本〕標準是每接一條動脈，至少接兩條靜脈，也就是 1A : 2V。 ⭐ 理由：手指再植失敗最主要的原因是「靜脈鬱血」，不是動脈栓塞。靜脈壁薄、內腔低壓、容易血栓，而且單一靜脈的輸出容量往往跟不上一條動脈的輸入量。 部位差異：越遠端（DIP 以遠、指尖）越難找到夠口徑的 dorsal vein。 ⭐ Artery-only replantation 的配套：① 拔除指甲、或做小切口，用 heparin 紗布持續放血 ② 醫用水蛭（medicinal leech）——⚠ 一定要合併預防性抗生素對抗 Aeromonas hydrophila（水蛭腸道共生菌），首選 ciprofloxacin 或第三代 cephalosporin，而且要準備輸血 ③ 也可以把斷指的另一條 digital artery 接到近端的靜脈當作 outflow（arteriovenous shunting）。

【三、什麼時候用 vein graft】 適應症：① 撕脫或壓砸傷，切除到健康血管後有 gap ② 不想再做 bone shortening（尤其斷面靠近關節、或必須保留長度）③ 血管出現 ribbon sign（血管呈緞帶狀彎曲）或 red line sign（血管外壁縱走的紅線），代表內膜已受傷、必須切除 ④ ⭐ 只要吻合口跨過 crush zone。 供區：掌側腕部／前臂遠端的 superficial vein（口徑 1–2 mm，與 digital artery 最匹配）、足背靜脈、大魚際區小靜脈。 技術：⭐ 用在動脈時必須「反轉方向（reversed）」以避開靜脈瓣；用在靜脈則不必反轉。長度要在關節活動的極端位置測量，寧長勿短，但過長會 kinking。 ⭐ 我的原則：只要切除到健康血管之後張力偏大，我不會猶豫——寧可再 shortening 0.5 公分，或直接拿 vein graft。因為在張力下做的吻合，幾乎注定會血栓。」

追問樹

  • 考官問「找不到靜脈怎麼辦？」 → 〔考生回憶‧邱浩遠實務訣竅〕「很 distal 找不到靜脈時，可以先接動脈、放開血管夾，觀察哪一條靜脈有 outflow；如果完全沒有，就拔指甲放血，甚至把斷指的另一條 digital artery 接到近端靜脈當作 outflow。」

  • 考官問「用水蛭要注意什麼？」 → 必須合併預防性抗生素對抗 Aeromonas hydrophila；並準備輸血（放血量可觀）。

再植與再血管化的術後照護與血循判讀（Postoperative monitoring; arterial versus venous compromise）

一句話定位：capillary refill「過快」代表鬱血——這是最常被誤判的一格，也是這一題的分水嶺。

核心模範答案

「報告老師，我分成監測方法、判讀、與處置三段。

【一、手指血循的七到八個判斷方法】 ① 顏色——粉紅色正常；蒼白發白＝動脈灌流不足；紫藍色＝靜脈鬱血。 ② 溫度——跟相鄰的正常手指比較，溫差超過 2°C 有意義。 ③ Capillary refill——正常 2 到 3 秒；⚠ 過快（小於 2 秒）反而代表靜脈鬱血——這是最常被誤判的地方；延長或消失代表動脈問題。 ④ Turgor（飽滿度）——飽脹是鬱血，塌陷萎縮是缺血。 ⑤ Pinprick test（最實用）——鮮紅色的血、2 秒內慢慢滲出＝血流正常；不出血或延遲、顏色淡＝動脈灌流不足；快速湧出暗紫色的血＝靜脈鬱血。 ⑥ Digital Allen test——分別壓住該指兩側的 digital artery，逐一放開比較。 ⑦ 手持式都卜勒（8–10 MHz）與 pulse oximetry——該指 SpO₂ 測不到或低於 95% 有參考價值。 ⑧ 客觀量化可用 digital brachial index；血管攝影／CTA 在急性手指損傷中很少用到。

【二、環境與藥物】 環境：室溫維持 25°C 以上、患肢抬高至心臟高度、⚠ 嚴格禁菸與禁咖啡因（尼古丁是最強的血管收縮劑）、避免使用血管收縮劑。 藥物：抗凝／抗血小板各家不同——aspirin 最常用；dextran 因過敏與肺水腫風險已較少用；heparin 用於高風險（撕脫傷、vein graft、多次重接）。⭐ 實證支持其實有限，照護品質遠比藥物重要。

壓砸手的評估與骨折處理：ligamentotaxis（Crush hand; ligamentotaxis and traction K-pin）

手外科與周邊神經 · 🟠

一句話定位：只講 ORIF 等於沒答到——邱浩遠 2025 年整關的設計就是為了逼出 ligamentotaxis；⚠ 而且不要推薦 Suzuki frame。

核心模範答案

「報告老師，我先講評估，再講骨折的處理。

【一、評估——按五個系統逐一清點】 先講受傷機轉：這是 crush injury，跟切割傷完全不同——壓砸傷的血管與軟組織損傷是「節段性」的，範圍大於外觀所見，這會影響我所有後續的判斷。問清楚壓砸的物體、力道、時間、有沒有捲入（avulsion 成分）、污染程度、慣用手、職業、年齡、抽菸、共病、破傷風。 ① 皮膚與軟組織：撕脫範圍、有無 degloving、組織活性（顏色、出血、有無明顯界線）、缺損面積。 ② 骨骼與關節：畸形、異常活動、關節穩定度；影像照 AP、lateral、oblique 三個 view。 ③ 肌腱：分別測 FDS（其他手指固定在完全伸直位，測該指 PIP 主動屈曲）與 FDP（固定 PIP，測 DIP 屈曲）；伸肌看主動伸直與 tenodesis effect（病人不合作時，被動屈伸腕部觀察手指連動，可判斷肌腱連續性）。 ④ 神經：每一隻手指的兩側 digital nerve 都要分開測，做 static 與 moving 2-point discrimination（正常指腹 static <6 mm）；不合作或小孩可用 wrinkle test 或 ninhydrin test。 ⑤ 血循：見前一則主題的七到八項。⚠ 並警覺 compartment syndrome。 同時抽血、備血、抗生素、破傷風，並在急診就移除所有戒指與束縛物、抬高患肢。

【二、骨折的處理——⭐ 關節內粉碎性骨折走 ligamentotaxis】 關節內的粉碎性骨折（例如 middle phalanx base 的 pilon fracture）： 原則上骨折要「穩定固定 ＋ 早期活動」，但這個病人有兩個限制：第一，這是 crush injury，軟組織條件很差；第二，該指的血循本來就不好。如果我為了 ORIF 而做大範圍剝離，會犧牲僅存的骨膜血循與軟組織，反而讓整根手指陷入危險；而且關節面已經粉碎，直接固定每一塊碎片幾乎不可能。 ⭐ 所以我選擇 ligamentotaxis（韌帶牽引復位）。原理是：利用完好的 collateral ligament 與 volar plate 作為軟組織鉸鏈，在持續的軸向牽引下，把附著在這些韌帶上的關節面碎片「間接」拉回原位。這是 indirect reduction，最大的好處是不需要打開關節、不破壞血循。 ⭐ 具體做法我選 traction K-pin ＋ dynamic splint：在遠端橫穿一根克氏鋼針，用彎成弓形的外掛支架（outrigger）加上橡皮筋提供持續軸向牽引。最大優點是——牽引與活動可以並存，病人在牽引狀態下就可以開始保護性的主動與被動 ROM。 ⚠ 另一個常被提到的選項是 Suzuki frame（pins and rubbers traction system），原理相同。但我個人的考量是——它需要現場把多根克氏針彎製成特定形狀，製作不容易，而且一旦成形，牽引的向量就很難再調整；相較之下，traction K-pin 加 dynamic splint 只要換橡皮筋或調整 outrigger 的角度，就可以隨時修正向量。

【三、關節外的骨折】 例如 proximal phalangeal neck fracture：肌腱完好且可閉鎖復位 → closed reduction ＋ percutaneous K-wire（交叉或髓內固定）；不穩定或傷口已暴露骨折處 → mini-plate 或 lag screw，⚠ 但要跟病人說明——指骨上放骨板的肌腱沾黏風險相當高，可能需要二期做 tenolysis。」

殘缺手的重建目標：basic hand 四要素、pollicization 與 toe-to-hand（Mutilated hand reconstruction）

手外科與周邊神經 · 🟠

一句話定位：先講「basic hand 的四個要素」當骨架，再逐項檢視這隻手缺了哪一項——這是所有殘缺手題目的萬用答題結構。

核心模範答案

「報告老師，⭐ 這是一隻 mutilated hand。我的答題骨架是先建立重建的目標，再逐項檢視。

【⭐ Basic（functional）hand 的四個要素】 ① 穩定且無痛的手腕（stable, painless wrist）——所有手部功能的基座。 ② 可對掌且有感覺的拇指（opposable, sensate thumb）——拇指佔手部功能的一半。 ③ 足夠深且寬的第一指蹼（deep and wide first web space）——沒有指蹼就沒有 span grasp。 ④ 至少兩根可對到拇指的手指（two digits for pinch／two ulnar digits for grasp grip）。 ⭐ 加分句：工作性質粗重的人以尺側手指的 power grip 為主；偏文書工作的人，橈側手指同樣重要，因為需要 fine pinch。「重建的目標要依病人的職業調整。」

【逐項檢視這隻手】 指出缺損破壞了哪幾項（拇指長度、對掌、第一指蹼、感覺），然後分兩步走：① 先求存活與覆蓋——把外露的骨頭蓋起來、保留現有骨骼長度，等軟組織穩定；② 再求重建功能——重建拇指與捏合。

【拇指重建的階梯（依缺損 level）】 ① 遠端缺損（保留 CMC 與足夠長度）→ 軟組織覆蓋即可：Moberg volar advancement flap（拇指專用，最多 1–1.5 cm）、FDMA（kite）flap、cross-finger flap。 ② 中段缺損（拇指過短，但 CMC joint 與 thenar 完好）→ phalangization／web deepening ＋ 骨延長（distraction lengthening）、osteoplastic reconstruction（iliac bone graft ＋ groin flap ＋ neurovascular island flap）。 ③ 近端缺損、thenar 功能喪失 → pollicization 或 toe-to-hand transfer。

【⭐ Pollicization vs Toe-to-hand 的選擇】

  • Pollicization：不需顯微吻合、一次完成、感覺與活動度好；代價是少一根手指——所以適合該指本來就無功能或已毀損的情況。傳統用 index finger（Buck-Gramcko），但 index 已毀損時可以用任何一根仍有良好神經血管束與關節的手指。
  • Toe-to-hand transfer：不犧牲手上任何一根手指、可提供指甲與較接近的外觀；代價是需要顯微吻合、足部供區病態，且需要 thenar 與 CMC joint 完好。

【軟組織覆蓋的階梯（依 reconstruction ladder）】 Local → Regional（reverse radial forearm flap、posterior interosseous artery flap、pedicled groin／abdominal flap）→ Free（ALT、SCIP、free toe transfer、LD muscle flap ＋ STSG）。 ⚠ 選 reverse RFFF 要先做 Allen test；且在 crush injury 中，橈動脈本身可能就在 zone of injury 內——這時可考慮對側 RFFF，但病人只剩一隻手時，對側手部功能必須謹慎評估。」

追問樹

  • 考官問「這麼遠距離的 pollicization 會遇到什麼問題？」 → ① ⭐ 神經血管束的長度不足——digital nerve 與 artery 必須從 common digital 分叉處往近端做 interfascicular dissection，才能得到足夠旋轉長度而不造成張力；neurovascular pedicle 是限制轉位距離的第一因素。② 靜脈回流——背側靜脈網必須連同皮橋保留。③ 相鄰指的血流犧牲——常需結紮一側 digital artery，必須先確認相鄰指的另一側動脈通暢。④ 轉位後的擺位——pronation 約 120–160°、palmar abduction 約 40°，並把 metacarpal head 重塑成新的 trapezium。⑤ 肌肉重新命名（rebalancing）——interossei 重建為新的 abductor 與 adductor pollicis；EIP → EPL、EDC → APL。⑥ 感覺與皮質重塑——成人比兒童困難，需長時間職能治療。
  • 考官問「重建後功能會回到多少？」 → ⭐ 安全講法：「文獻上 pollicization 後的手部功能可恢復到正常的 50–70%，但更重要的是它把一隻『不能捏東西的手』變成『可以捏東西的手』——這個質變比百分比更有意義。」
  • 考官問「合併 median ＋ ulnar 損傷要先重建什麼？」 → 依 basic hand 優先序：① 拇指的對掌與感覺 ② 對指的 key pinch ③ 手指屈曲的動力 ④ 感覺重建（尤其拇指尺側與食指橈側，這是 pinch 的接觸面）。所以 opponensplasty 是第一優先。
  • 考官問「哪些指頭可以接？」 → 先重建拇指；斷指品質不好時可做 heterotopic／transposition replantation（把品質好的斷指接到功能更重要的位置）；⭐ 接回的手指要盡量「相鄰」，功能才好——分散的手指無法對捏。

腕骨解剖、Kaplan's cardinal line 與 hook of hamate（Carpal bones and palmar landmarks）

手外科與周邊神經 · 🟠

一句話定位：八塊骨頭是背誦題，但真正的考點是 hook of hamate 與 Kaplan's line 的臨床對應。

核心模範答案

「報告老師，腕骨八塊，我用口訣『舟月三豆、大小頭鉤』。

【近端排（Proximal row，橈→尺）】 Scaphoid（舟狀骨）、Lunate（月狀骨）、Triquetrum（三角骨）、Pisiform（豆狀骨）。 【遠端排（Distal row，橈→尺）】 Trapezium（大多角骨）、Trapezoid（小多角骨）、Capitate（頭狀骨）、Hamate（鉤狀骨）。

【⭐ Hook of hamate 的三個臨床身分】 ① 它是 Guyon's canal 的橈側（外側）壁；② 它是 transverse carpal ligament 的尺側附著點；③ 它是 Kaplan's cardinal line 的尺側終點。 臨床上——hook of hamate fracture（高爾夫、球棒握把的直接撞擊）是 ulnar nerve deep motor branch 壓迫的典型原因。

【⭐ Kaplan's cardinal line——沿線可定位四個深部構造】 畫法：從拇指完全外展時第一指蹼的頂點（apex of first web），畫一條「平行於 proximal palmar crease」的線，往尺側延伸至 hook of hamate。 ① 與「第三指蹼」縱軸的交點 ＝ median nerve 的 recurrent motor branch（拇指對掌肌群的運動支）。 ② 與「第四指蹼」縱軸的交點 ＝ ulnar nerve 的 deep motor branch。 ③ superficial palmar arch 約在此線的「遠端 1 公分」；deep palmar arch 在其「近端約 1 公分」。 ④ 尺側終點 ＝ hook of hamate。

【兩個常被追問的補充】

  • Pisiform 是全身唯一位於肌腱內的腕骨——它是 FCU 肌腱內的 sesamoid bone，不參與腕關節的近端關節面。
  • 血流特性：Scaphoid 的血流由「遠端」進入（retrograde intraosseous blood supply），所以 proximal pole fracture 有高 nonunion 與 AVN 風險（Preiser disease）；Lunate 的 AVN 則是 Kienböck disease。」

追問樹

  • 考官問「為什麼 recurrent motor branch 這麼重要？」 → 它是 CTS 手術中最容易誤傷的分支；⚠ 所以切口要偏「尺側」，同時避開 palmar cutaneous branch。
  • 考官問「手指的橫切面怎麼畫？」 → ⭐ 中央偏背側是 phalanx（骨頭在「北半球」）；flexor tendon 在正掌側（約 6 點鐘）；兩側的 neurovascular bundle 各在約 4–5 點與 7–8 點鐘方向（也可講 2 點與 10 點的掌側偏兩側），⭐ 動脈在神經的「背側」、神經在動脈的「掌側」；背側有 extensor mechanism 與 dorsal veins（12 點鐘附近，靜脈在皮下淺層）。臨床意義：找靜脈要在背側皮下最淺層找；找動脈要沿骨頭兩側的中軸線找，且神經比動脈更靠掌側。

舟狀骨骨折的理學檢查與影像選擇（Scaphoid fracture: MRI versus CT）

一句話定位：「懷疑但 X 光陰性 → MRI；已確診、要看位移與規劃手術 → CT」——這一句分流講出來，這題就過了。

核心模範答案

「報告老師，Scaphoid fracture 是手腕最常被漏診的骨折，所以我的 approach 是「臨床懷疑優先於影像」。

【理學檢查三個經典徵象】 ① Anatomical snuffbox tenderness——敏感度很高但特異度低。 ② Scaphoid tubercle tenderness——從掌側、遠端腕橫紋橈側按壓。 ③ Longitudinal／axial thumb compression pain——沿拇指縱軸敲擊或加壓。 ⭐ 三者同時陽性時陽性預測值才高；三者都陰性時幾乎可以排除。另外要看握力下降與 wrist ROM 受限，並檢查有無合併 scapholunate 不穩定（Watson scaphoid shift test）。

【影像】 X 光四個 view：PA、lateral、45 度旋前斜位、以及 scaphoid view（尺偏位的 PA，可以把 scaphoid 拉長）。 ⭐ 但這裡有一個關鍵：〔課本〕高達 25% 的 scaphoid fracture 在初次 X 光上看不到，也就是 occult fracture。所以只要臨床高度懷疑而 X 光陰性，我不會放病人走。

【⭐ 為什麼選 MRI 不選 CT】 MRI 對隱匿性骨折的敏感度與特異度最高、接近 100%，而且在受傷後 24 小時內就可以偵測到 bone marrow edema；同時它還可以評估 scapholunate 與 lunotriquetral 韌帶，以及 proximal pole 有沒有缺血壞死的訊號變化。 CT 的角色不同：CT 是「看骨頭形態」的工具——評估位移程度、粉碎、humpback deformity、以及癒合時的 bridging trabeculae。 ⭐ 所以我的分流是：懷疑但 X 光陰性 → MRI；已確診、要看位移與規劃手術 → CT。」

追問樹

  • 考官問「為什麼 scaphoid 特別容易不癒合、特別容易缺血壞死？」 → 〔課本〕scaphoid 有 80% 的表面被關節軟骨覆蓋，可供血管進入的骨面極少；血流主要來自 radial artery 的 dorsal ridge branch，供應 proximal pole 的 70–80%，而且是「逆行（retrograde）」的。所以骨折線越靠近 proximal，缺血壞死與不癒合的機率越高——proximal pole 骨折的 AVN 率可達 30–40%。
  • 考官問「怎麼治療？」 → 無位移的 distal pole 或 waist 骨折：thumb spica cast 6–12 週；waist 骨折若病人需早日回工作，可考慮 percutaneous headless compression screw。手術適應症：位移 >1 mm、humpback deformity（lateral intrascaphoid angle 增大）、proximal pole 骨折、合併腕骨不穩定、不癒合 → ORIF with headless compression screw（Herbert／Acutrak）。不癒合合併 AVN → 帶血管的骨移植：1,2-ICSRA 的 distal radius vascularized bone graft，或游離的 medial femoral condyle flap。
  • 考官問「長期不處理會怎樣？」 → 走向 SNAC wrist（scaphoid nonunion advanced collapse）：依序是 radial styloid 關節炎 → scaphocapitate 關節炎 → 全腕塌陷；處理依分期做 radial styloidectomy、proximal row carpectomy 或 four-corner fusion。
  • 加分句 → 「我在急診的實際做法是：臨床三個徵象只要陽性，即使 X 光乾淨，我一律先給 thumb spica 副木固定並約回診；能安排 MRI 就在 3 到 5 天內安排。因為漏掉一個 scaphoid fracture 的代價是 SNAC wrist，那是一輩子的事。」

「報告老師，Lister's tubercle 是橈骨遠端「背側」的骨性隆起，是第 2 與第 3 背側腔室的分界。

【定位方法】 從橈骨莖突往背側與尺側移動約 1 公分，在腕關節近端可以摸到的那個小骨結節。 ⚠ 它在 dorsum of distal radius，不要與腕骨（舟狀骨、月狀骨）的隆起弄錯。

【與 EPL 的關聯】 EPL 走在 Lister's tubercle 的「尺側」，繞過這個結節後轉向橈側前往拇指——⭐ 所以 Lister's tubercle 等於是 EPL 的一個滑車（pulley）。

【三個臨床意義】 ① 橈骨遠端骨折（尤其是「無位移」的 Colles' fracture）之後的遲發性 EPL 斷裂——因為結節處同時是血流的分水嶺（watershed area），又有機械性摩擦。 ② EPL 斷裂後回縮非常嚴重——可沿著 Lister's tubercle 的「尺側」往近端追，找出肌腱。 ③ 治療通常「不做直接修補」（肌腱已退化、回縮太多），標準做法是 EIP → EPL tendon transfer。

【六個背側腔室（順帶背出來會加分）】 1 ＝ APL + EPB｜2 ＝ ECRL + ECRB｜3 ＝ EPL（在 Lister's tubercle 的尺側繞行）｜4 ＝ EDC + EIP｜5 ＝ EDM｜6 ＝ ECU。」

追問樹

  • 考官問「Extensor tendon 由淺層到深層的構造？」 → 淺層：Brachioradialis、ECRL、ECRB、EDC、EDM（EDQ）、ECU。深層：Supinator、APL、EPB、EPL、EIP。
  • 考官問「取 EIP 做 transfer 要怎麼在術中認出來？」 → ⭐ 兩個要點：① EIP 位於 EDC 的「尺側」且較深；② 在 wrist level 可以看到 EIP 的 muscle belly（EDC 的肌腹在前臂中段就結束了）——往近端追，還帶著肌肉的就是 EIP。
  • 考官問「取 EIP 的代價？」 → 食指失去獨立伸指（EDC 仍可伸）、不減少握力、不需 pulley 或 tendon graft。張力調整：wrist flexion 30°、thumb 在 full opposition 位置。

屈指淺肌的檢查、原理與深淺排列（FDS test; FDS tendon arrangement）

手外科與周邊神經 · 🔴

一句話定位：考官問的是「原理」，不是「做法」——而 30–35% 小指 FDS 缺如的陷阱要主動講出來。

核心模範答案

「報告老師，FDS test 的做法是：把其他所有手指固定在完全伸直的位置，然後請病人單獨屈曲受測手指的 PIP joint。

【⭐ 原理——他問的就是這個】 FDP 的四條肌腱共用一個 common muscle belly。把其他手指固定在伸直位，等於把 FDP 的肌腹「鎖住」，讓它無法作用於受測的手指。因此這時候 PIP 能夠屈曲，力量就只可能來自 FDS。

【判讀】 完全不能動 ＝ 完全斷裂；能動但無力 ＝ 部分斷裂。

【⚠ 陷阱——一定要主動講出來】 有 30% 到 35% 的人，小指的 FDS 缺如、或與環指的 FDS 相連。所以測小指時如果把環指壓住，會誤判為 FDS 斷裂——測小指要允許環指一起動。

【對照：FDP 的測法】 固定 PIP joint，測 DIP 能否主動屈曲。

【⭐ 腕部與遠端前臂的 FDS 深淺排列】 FDS 的四條肌腱不在同一平面：到「中指與環指」的 FDS 位於「淺層」；到「食指與小指」的 FDS 位於「深層」（在中指／環指的深面）。 ⭐ 記憶手勢：把中指與環指往前伸出來（淺），食指與小指縮在後面（深）。」

追問樹

  • 考官問「病人不合作怎麼辦？」 → 看 tenodesis effect——被動屈伸腕部，觀察手指的連動，可以判斷肌腱的連續性。
  • 考官問「Zone II 為什麼叫 no man's land？」 → FDS 與 FDP 在同一個腱鞘內滑動（FDS 在此分叉成兩束、繞到 FDP 背側於 Camper's chiasm 交叉），修補後沾黏機率極高——這也是單指 zone II 斷離為什麼是 replantation 相對禁忌的原因。
  • 考官問「復健什麼時候開始？」 → 單純 sharp laceration 且 4-strand 以上縫合 → early protected／active motion；crush 或多重組織損傷 → 屈肌腱約 3 週、伸肌腱約 4 週（成大版）。

Jersey finger 與 FDP 撕脫（Jersey finger; FDP avulsion; Leddy–Packer classification）

手外科與周邊神經 · 🔴

一句話定位：簡守信 104–111 每年必出的影片題——分型的價值在於它直接決定「你有幾天可以開刀」。

核心模範答案

「報告老師，影片顯示病人在固定 PIP joint 的情況下無法主動屈曲 DIP joint，代表 FDP 的連續性中斷，診斷是 FDP disruption。 若病史是橄欖球／柔道抓對方球衣時被強力拉開，即為典型的 Jersey finger（closed FDP avulsion），⭐ 好發於 ring finger——因為環指的 FDP 止點抗拉強度較弱，而且伸指時它最突出。

【理學檢查】 固定 PIP 測 DIP 主動屈曲 ＝ 測 FDP；固定其餘手指的 DIP 於伸直位測 PIP 屈曲 ＝ 測 FDS。掌側可能沿腱鞘有壓痛，可依壓痛最遠端推測肌腱回縮的位置。

【⭐ 分型：Leddy–Packer classification——它決定手術的時間窗】

  • Type I：肌腱回縮到手掌（vincula 斷裂、血供中斷）→ ⭐ 必須在 7–10 天內修補，否則肌腱攣縮壞死。
  • Type II：回縮到 PIP 高度（vincula 仍完整）→ 可容忍到 6 週。
  • Type III：帶大塊撕脫骨片卡在 A4 pulley，回縮有限。
  • Type IV：骨折併肌腱自骨片再撕脫（雙重損傷）。
  • （Smith 追加）Type V：合併 distal phalanx 粉碎性骨折。

【治療】 急性期做 primary repair／reinsertion（pull-out suture 或 bone anchor）。 慢性、已無法直接修補者 → two-stage tendon graft、DIP arthrodesis 或 tenodesis；⚠ 但要先與病人溝通——單獨 DIP 屈曲喪失的功能影響有限，不一定要積極重建。」

追問樹

  • 考官問「Mallet finger 跟它有什麼不同？」 → Jersey ＝ FDP avulsion（屈不起來）；Mallet ＝ 終端伸肌腱在 DIP 止點斷裂或撕脫骨折（伸不直）。Mallet 用 Doyle 分類，治療以 DIP 持續伸直副木 6–8 週（Stack splint）為主，僅在大骨片＋掌側半脫位時手術。
  • 考官問「為什麼 Type I 只有 7–10 天？」 → vincula 是 FDP 的血液供應來源；vincula 一併斷裂後肌腱失去血供、且回縮到手掌後在腱鞘內攣縮，超過 7–10 天就無法拉回原位、也無法存活。
  • 考官問「重建的併發症？」 → quadriga effect（FDP 縫得太緊或太短，因共用肌腹而拖累其他手指的屈曲）、lumbrical-plus finger（肌腱移植過長 → 越用力屈指、PIP 反而伸直的矛盾動作）。

伸肌機轉：Mallet、Swan neck、Boutonnière（Extensor mechanism; central slip and lateral band）

手外科與周邊神經 · 🟠

一句話定位：三個變形其實是同一套滑移系統在不同位置失效——能把它們串成一條因果鏈，就贏了。

核心模範答案

「報告老師，我先講伸肌機轉的設計，再講三個變形。

【⭐ 伸肌機轉的設計與「為什麼 central slip 不直接接到遠節」】 central slip 止於「中節指骨基部」負責 PIP 伸展；兩條 lateral band 在 PIP 之後匯合成 terminal tendon、止於「遠節指骨基部」負責 DIP 伸展；而 lumbrical 與 interossei 由掌側經 lateral band 併入這個系統。 ⭐ 如果 central slip 直接接到遠節指骨，整根手指的伸展就變成一個「剛性的單一單元」，ROM 會嚴重受限。實際的伸肌機轉是一個可分散、可滑移的網狀系統——這樣的設計讓 PIP 與 DIP 可以「分別」也可以「連動」地伸展，並讓 intrinsic 與 extrinsic 肌肉共用同一套滑移機制。這就是 synergy。

【三個變形】 ① Mallet finger：terminal extensor tendon 在 DIP 止點斷裂（或伴 bony avulsion）→ DIP extension lag。 治療：DIP 持續伸直副木 6–8 週（Stack splint），⚠ 不可中斷；bony mallet 若關節面受累超過三分之一或有掌側半脫位 → extension-block pinning／ORIF。 ② Boutonnière：central slip 在中節指骨基部斷裂 → lateral band 向掌側滑落到 PIP 旋轉軸的掌側 → 由「伸 PIP」變成「屈 PIP」→ PIP flexion ＋ DIP hyperextension。 檢查 ＝ ⭐ Elson test：PIP 屈曲 90° 抵住桌緣，請病人伸 PIP——若 DIP 變得僵硬伸直即為陽性（因為力量全跑到 lateral band）。 治療：急性期 PIP 伸直副木 6 週、DIP 自由活動；慢性期先恢復被動活動度再手術（central slip reconstruction、Fowler／Dolphin terminal tenotomy）。 ③ Swan neck：PIP hyperextension ＋ DIP flexion。 成因：慢性 mallet（terminal tendon 斷 → lateral band 向背側移位、張力全跑到 PIP）、FDS 斷裂／volar plate 鬆弛、intrinsic tightness（RA）、關節過動。 檢查 Bunnell intrinsic tightness test。 治療：SORL reconstruction（Littler，spiral oblique retinacular ligament）、FDS tenodesis、silicone ring splint。

【⭐ 一句串起來的因果鏈】 central slip 斷 → boutonnière；terminal tendon 斷 → mallet；慢性 mallet → swan neck。三個變形，就是同一套滑移系統在不同位置失效的結果。」

掌腱膜攣縮症（Dupuytren's disease）

手外科與周邊神經 · 🔴

一句話定位：⚠ 看到圖直接喊 Dupuytren 是地雷——邱浩遠要的是「先鋪鑑別診斷、再用 skin retraction 收束」這個 reasoning 的過程。

核心模範答案

「報告老師，我先做鑑別診斷。手掌／指基部的腫塊或凹陷，常見的有—— ① Ganglion cyst：好發於背側腕部（60–70%，源自 scapholunate interosseous ligament），其次是掌側腕部（20%，源自 scapho-trapezio-trapezoid ligament），以及 volar retinacular（10–20%）。 ② Giant cell tumor of tendon sheath（＝ localized pigmented villonodular synovitis）：堅硬、不痛、結節狀、生長緩慢。 ③ Epidermal inclusion cyst。 ④ Trigger finger（A1 pulley 處的 Notta's node）。 ⑤ Knuckle pad（Garrod's node）——⚠ 但這個在 PIP 背側，位置不對。

⭐ 但這個病灶的關鍵是——它是『凹進去』的，周圍有 skin tethering（皮膚被牽住、內陷）。其他腫瘤都是往外凸的 mass effect，只有 Dupuytren 因為病變的筋膜與真皮相連，會造成 skin retraction。所以我的診斷是 Dupuytren's disease。 ⭐ 最早出現的徵象是 Hueston（Hugh Johnson）sign——手掌的 pitting／dimpling，遠端掌橫紋變形加深或變寬。結節（nodule）其實是第二個才出現的。

【⭐ 解剖——他會要你背這一段】 本質：palmar aponeurosis（palmar fascia）的纖維增生性疾病；病理是 myofibroblast 增生與 type III collagen 增加；⭐ 深度只到 palmar fascia、就在皮下〔考生回憶‧邱浩遠原話：「沒經驗的常常一刀劃下去就超過」〕。 ⭐ 正常結構叫 band，病態化之後才叫 cord：

  • Pretendinous band → pretendinous cord（造成 MCP 攣縮）
  • Natatory ligament → natatory cord（造成 web space 攣縮、手指無法外展）
  • ⭐⭐ Spiral cord（由 pretendinous band ＋ spiral band（Gosset）＋ lateral digital sheet ＋ Grayson's ligament 四者共同組成）→ 造成 PIP 攣縮，而且會把 neurovascular bundle 拉向「淺層、中線、近端」——這是術中傷到神經血管束的最大原因。
  • Lateral cord（來自 lateral digital sheet）→ PIP／DIP 攣縮
  • Retrovascular cord（Thomine）→ DIP 攣縮，也是復發常見來源
  • Central cord、Abductor digiti minimi cord（小指常見）

⭐ Grayson's vs Cleland's：Grayson's 在掌側、Cleland's 在背側，兩者一前一後把 neurovascular bundle 包在中間。⭐ Grayson's 會受侵犯、Cleland's 不受侵犯（記法：C 在 Ceiling／天花板，不受影響）。

  • 考官問「MCP 超過 30 度就一定要開嗎？」 → ⭐ 有標準答案，而且考官會用力點頭：「不一定。」理由要講機轉——MCP 關節的 collateral ligament 在屈曲位時本來就是被拉長的，所以不會攣縮；因此 MCP 的攣縮即使拖久了，手術後矯正的結果仍然很好。反過來說，PIP 關節的 volar plate、checkrein ligament 與 collateral ligament 都會隨時間攣縮，越晚開結果越差。⭐ 所以正確的臨床原則是：PIP 一旦有攣縮就該積極考慮手術；MCP 反而可以觀察。
  • 考官問「為什麼 MCP 的手術結果永遠比 PIP 好？」 → 同上；加分句：「MP 的攣縮主要是 cord 的機械性牽拉，切掉就鬆了；PIP 拖久了是關節本身（volar plate、checkrein、副韌帶）的續發攣縮，光切 cord 是不夠的。」
  • 考官問「這算不算 knuckle pad？」 → 不是——〔考生回憶：考官親自否定〕knuckle pad（Garrod's node）在 PIP 背側，位置不對。

Allen test 的操作、原理與歷史（Allen's test）

手外科與周邊神經 · 🟠

一句話定位：這是「考官把手借給你」的操作題——⚠ 把考官的手腕壓出指甲痕是明列地雷。

核心模範答案（邊做邊講）

「報告老師，Allen test 是用來評估手部 radial artery 與 ulnar artery 之間，經由 superficial 與 deep palmar arch 的側支循環是否足夠。

【操作 — modified Allen test】 ① 請病人把手抬高、放在桌上，用力握拳約 30 秒（或反覆握拳伸直數次，最後握緊把血驅出）； ② 我用兩隻手指「同時」壓住手腕的 radial 與 ulnar artery； ③ 請病人「輕輕」張開手掌——此時手掌應呈蒼白（pale）；⚠ 注意手不要過度伸展，否則會因為皮膚張力造成偽陽性； ④ 先放開 ulnar artery、繼續壓著 radial artery，觀察手掌恢復紅潤（blush）的時間——正常應在 5 到 15 秒內全掌恢復血色（一般以 < 6 秒為正常、7–15 秒為 equivocal、> 15 秒為異常；另有教科書寫 7 到 10 秒內恢復即為正常）； ⑤ 重複同一動作，這次改放開 radial artery，測試另一條血管。

【判讀】 若放開 ulnar artery 後手掌未在時間內恢復血色，代表 ulnar artery 的供血或 palmar arch 的側支循環不足——此時若切取 radial artery（如 radial forearm flap）會有手部缺血的風險，應改選其他皮瓣。

【原理】 手掌由 radial 與 ulnar 兩條動脈經 superficial palmar arch（主要由 ulnar artery 供應）與 deep palmar arch（主要由 radial artery 供應）形成環狀吻合。這個測試就是人為阻斷其中一條，測試另一條能否單獨供應整個手掌。

【臨床用途】 取 radial forearm flap 之前必做、放置動脈導管之前、radial artery 取作冠狀動脈繞道之前、懷疑 ulnar artery 損傷或 hypothenar hammer syndrome 時。

【延伸】 Digital Allen test——同樣原理壓住單指兩側的 digital artery，評估單一手指的血流。」

追問樹

  • 考官問「怎麼跟病人解釋檢查結果？」 → 「您的手掌有兩條主要的血管在供血，這個檢查是要確認萬一我們用掉其中一條，另一條能不能單獨養活整隻手。您的結果是正常的（或不夠理想），所以我們（可以／不建議）採用這個部位的皮瓣。」
  • 考官問「Allen 是誰？」 → ⭐〔林煌基 109 年真的問過〕「Edgar Van Nuys Allen，梅約醫學中心的內科醫師，於 1929 年首先描述，原始目的是評估 thromboangiitis obliterans（Buerger's disease）病人的血管通暢度，原始做法是雙手同時檢查。1952 年 Irving S. Wright 提出的修改版本（modified Allen test）以單手、逐一釋放的方式進行，現已幾乎完全取代原始方法。」⚠ 加分：林主任本人在 Mayo Clinic 進修過——講到這一句，這關就穩了。
  • 考官問「什麼時候會偽陽性？」 → ① 手指過度伸展（皮膚張力）② 壓迫不完全 ③ 病人手冷、末梢血管收縮 ④ 貧血或低血壓。

De Quervain 症與 Finkelstein test（Finkelstein test; de Quervain's tenosynovitis）

手外科與周邊神經 · 🟠

一句話定位：他會要你「寫出全名」——而 35–45% 的 septum 才是這題真正的臨床重點。

核心模範答案

「報告老師，診斷的全名是 De Quervain's disease ＝ stenosing tenosynovitis of the first dorsal (extensor) compartment（第一背側伸肌腔室的狹窄性腱鞘炎）。

【做法】 拇指內收、屈曲進掌心（或由檢查者握住拇指），然後手腕向「尺側」偏移；橈骨莖突處第一腔室劇痛為陽性。

【⚠ 學術上的精確區分（講出來很加分）】 病人自己握拳包住拇指再尺偏，嚴格說是 Eichhoff test；Finkelstein 的原始描述是「檢查者拉住拇指做縱向牽引再尺偏」。近年文獻認為 WHAT test（Wrist Hyperflexion and Abduction of the Thumb） 的特異度更高。

【解剖】 第一背側腔室含 APL 與 EPB。 ⭐ 關鍵臨床細節：35% 到 45% 的人，APL 與 EPB 之間有一道 septum 把腔室分成兩個小隔間。這正是類固醇注射效果不佳、以及手術後仍有症狀的最常見原因——注射或放開時「兩個小隔間都必須處理到」。

【流行病學】 男女比約 1:10，好發 35 到 55 歲，產後與哺乳期婦女特別多。

【治療】 拇指人字副木 4 到 6 週、類固醇注射是第一線的介入；無效再手術——⭐ 切口沿 extensor retinaculum 的「尺側緣」放開（避免肌腱向掌側半脫位），術中小心 superficial radial nerve 與 radial artery。」

追問樹

  • 考官問「鑑別診斷有哪些？」 → 拇指 CMC 關節炎（basal joint arthritis，Grind test 陽性）、intersection syndrome（位置更近端，約橈骨莖突近端 4–6 cm）、Wartenberg syndrome（superficial radial nerve 壓迫，純感覺）、scaphoid fracture、STT 關節炎。
  • 考官問「為什麼注射打不好？」 → 就是那道 septum——要把針分別送進 APL 與 EPB 兩個隔間，或術中確認兩個隔間都放開。
  • 考官問「切口為什麼要沿尺側緣？」 → 保留橈側的 retinaculum 作為「牆」，避免放開後肌腱向掌側半脫位（volar subluxation）。

板機指與 A1 pulley 注射（Trigger finger/thumb; A1 pulley injection）

一句話定位：簡守信 104–111 每年必出的影片題，而他真正追問的是「local 要打在哪裡」這個操作細節。

Z-plasty 的角度與延長率（Z-plasty geometry）

手外科與周邊神經 · 🟠

一句話定位：純記憶題，必背——但要能同時說出「為什麼 60 度是實務標準」。

核心模範答案

「報告老師，Z-plasty 的角度與理論延長率是： 30° → 25%｜45° → 50%｜60° → 75%｜75° → 100%｜90° → 120%。

⭐ 60 度是實務上的標準，因為它在「延長效果」與「皮瓣尖端的血循安全」之間最平衡——角度越大延長越多，但皮瓣越難轉、尖端越容易壞死；角度太小則延長不足、皮瓣太細也容易缺血。

【臨床應用】 ① 手部：指蹼攣縮（web space contracture）、Dupuytren 術後的傷口關閉（縱向切口 ＋ 小 Z-plasty）、燒傷後的線性攣縮。 ② 變化型：four-flap Z-plasty（適合第一指蹼加深，可得到更大的延長）、five-flap（jumping man）Z-plasty、series（multiple）Z-plasty——多個小 Z 的總延長量大、且每個皮瓣血循更安全、疤痕更分散。 ③ ⭐ 原則：把中央肢（central limb）放在攣縮帶（scar band）上，把最終的橫肢方向設計成與 RSTL 或美學單位交界平行。」

追問樹

  • 考官問「為什麼實際延長量常常小於理論值？」 → 理論值假設皮膚是無限可延展的；實際上受限於周邊皮膚的鬆弛度、疤痕組織的順應性、以及下方組織的固定，因此臨床上的實際延長多半低於理論值。
  • 考官問「指蹼攣縮用哪一種？」 → 第一指蹼優先考慮 four-flap Z-plasty 或 five-flap；⭐ 指蹼一定要用皮瓣重建，不能只靠植皮，否則必然 web creep。**

血管球瘤（Glomus tumor）

手外科與周邊神經 · 🟡

一句話定位：「碰冰水就劇痛、點得出來哪一點痛」＝ 臨床診斷，影像正常不能排除。

核心模範答案

「報告老師，這張圖我看到的是單一手指的 subungual 區域有一個界線清楚、略帶藍紫色的 discoloration，配合病史是年輕女性、冷刺激後劇痛——這個組合是 glomus tumor 的典型表現。

【臨床三徵】 ① paroxysmal severe pain（發作性劇痛）② cold sensitivity（碰冰水誘發）③ pinpoint tenderness（點狀壓痛，可用筆尖定位）。

【三個確認測試】 ① Love's pin test——用鉛筆尖逐點加壓，只有腫瘤那一點會劇痛。 ② ⭐ Hildreth test——上止血帶後同一點加壓疼痛消失、放鬆止血帶疼痛再現；這一項對 glomus tumor 的特異性最高。 ③ Cold sensitivity test——把手泡冰水疼痛加劇。

【細胞來源——他一定會問】 來自 glomus body，也就是 Sucquet–Hoyer canal 周圍的 neuromyoarterial apparatus。這是一個負責體溫調節的動靜脈吻合結構，腫瘤細胞是 modified smooth muscle cell（glomus cell）。⭐ 因為指甲下的 glomus body 密度最高，所以 subungual 是最好發的位置，好發於女性、30–50 歲。

【影像】 首選高解析度超音波與 MRI——MRI 上 T1 呈 low to intermediate signal、T2 呈 high signal，且 gadolinium 有很強的 enhancement，即使只有 2–3 mm 也能定位。X 光約 50% 可看到 distal phalanx 的 scalloping／pressure erosion。

【治療：完整手術切除，藥物無效——兩種 approach】 ① Transungual approach：移除 nail plate、在 sterile matrix 上做縱切、切除腫瘤後把 nail bed 顯微縫合、把 nail plate 回置當 splint；適合正中央的腫瘤。 ② Lateral subperiosteal（Littler）approach：從側方進入、不破壞 nail bed；適合偏側方的腫瘤。 復發率約 10%，多半是切除不完全或多發性病灶。」

追問樹

甲床解剖與甲溝炎（Nail bed anatomy; paronychia）

手外科與周邊神經 · 🟡

一句話定位：germinal matrix 受傷＝永久性指甲缺損——這是整個甲床解剖唯一真正的臨床分水嶺。

核心模範答案

「報告老師，Perionychium（整個甲床複合體）＝ nail plate ＋ nail bed ＋ 周邊構造。

【Nail bed 分兩段——這是關鍵】 ⭐ Germinal matrix（生發基質）：位於 lunula 及其近端，負責產生約 90% 的甲板厚度——⚠ 受傷會造成永久性的指甲缺損。 Sterile matrix（無菌基質）：lunula 遠端，讓甲板貼附並增加厚度。

【其他構造】 Eponychium（甲上皮，cuticle 所在的近端皺襞）、Paronychium（兩側皺襞）、Hyponychium（甲下皮，甲板遠端與指腹交界，是抵抗細菌的屏障）、Lunula（半月，germinal 與 sterile matrix 的分界）、Nail fold（含 dorsal roof 與 ventral floor）。

【⭐ 臨床重點】 Nail bed laceration 要用 6-0／7-0 可吸收線精細縫合，並把 nail plate 或替代物回置到 eponychial fold，以防 fold 沾黏造成日後指甲長不出來（synechia）。

【Paronychia（甲溝炎）】 ⭐〔李經維 107 年加碼題的正解〕發生的原因是——「指甲修得太寬、最側邊那一小條沒剪到，殘留的 lateral nail spike 像一把小刀一樣插進 lateral nail fold 的肉裡」，造成穿刺傷 → 細菌侵入 → acute paronychia。 〔課本〕：acute paronychia 最常見致病菌是 Staphylococcus aureus；chronic paronychia 則多為 Candida，加上潮濕職業與 cuticle 喪失。 治療：早期 warm soak ＋ 抗生素；已形成膿瘍則 incision & drainage，必要時做 partial nail plate removal。 ⭐ 預防的重點就是指甲要平剪到底、不要修圓。」

追問樹

  • 考官問「Subungual hematoma 要不要拔指甲？」 → 若指甲與甲襞完整、無明顯甲床撕裂，即使血腫面積大，現行做法多為單純 trephination（鑽孔引流）；只有在指甲已明顯脫離、或合併移位性 distal phalanx 骨折需修補甲床時才移除指甲。
  • 考官問「Hutchinson's sign 是什麼？」 → 甲下色素延伸到 proximal nail fold／eponychium 的皮膚，高度懷疑 subungual melanoma，必須 biopsy（掀甲取 nail matrix）。⚠ 需與「假性 Hutchinson's sign」（色素透過透明甲襞被看到）鑑別。
  • 考官問「Felon 跟 paronychia 差在哪？」 → Felon 是指腹（pulp）的閉鎖性間隔感染，張力高、劇痛，需要在側方切開引流並打開纖維間隔；paronychia 則侷限在甲襞。

一句話定位：決策原則是「保留長度與感覺」——指腹是負重面，不能用單純植皮應付。

核心模範答案

「報告老師，指腹重建我依缺損大小、有無骨外露、以及缺損的角度（volar oblique／transverse／dorsal oblique）來決定，並依 reconstruction ladder 往上走。

戒指撕脫傷（Ring avulsion injury; Urbaniak classification）

手外科與周邊神經 · 🟡

一句話定位：撕脫傷的鐵律——血管必須切除到明顯正常的內膜，寧可用 vein graft，也不要在受傷的血管上吻合。

核心模範答案

「報告老師，戒指撕脫傷我用 Urbaniak 分類。

【分類】

  • Class I——循環尚足夠（僅軟組織損傷）。
  • Class II——循環不足，需要 revascularization；可再細分：IIa 只有動脈受損；IIb 動脈加骨骼／肌腱；IIc 靜脈也受損。
  • Class III——完全撕脫（complete degloving）或完全截肢。

⭐ Kay modification 再加入「骨骼是否受傷」這個變數。

【處理】

  • Class I → 保守／清創縫合。
  • Class II → 積極 revascularization；⚠ 常需要 vein graft，因為撕脫傷的血管內膜受損範圍遠超肉眼所見。
  • Class III → replantation 成功率低、結果差，傳統建議 revision amputation；但在拇指或多指的情況下仍應嘗試。

【⭐ 撕脫傷的鐵律】 術中看到 ribbon sign（血管呈緞帶狀彎曲）或 red line sign（血管外壁縱走的紅線），就代表內膜已經受傷——必須切除到明顯正常的內膜，寧可用 vein graft，也不要在受傷的血管上吻合。」

追問樹

  • 考官問「Class III 一定要截肢嗎？」 → 不一定——拇指或多指時仍應嘗試；⚠ 但要事先與病人溝通成功率與可能需要多次手術、長期復健，以及最終功能可能不如義肢或截肢後重建。

先天性併指（Congenital syndactyly; web deepening and the high-riding neurovascular bundle）

手外科與周邊神經 · 🟡

一句話定位：「為什麼前一位醫師沒開完全」的答案是 high-riding neurovascular bundle——這是江原正這一題的核心。

核心模範答案

「報告老師，我先描述、最後才給診斷。

【描述的七個維度（他明確要的）】 ① complete（到指尖含甲襞）vs incomplete（未到指尖）；② simple（僅皮膚軟組織）vs complex（有骨性融合）vs complicated（有額外的骨骼／異常結構，如 Apert 手）；③ 單側 vs 雙側；④ 只有手 or 手與腳都有；⑤ 是哪幾指（⭐ 最常見是第 3–4 指蹼，約 50%）；⑥ 有無合併其他變形（camptodactyly、clinodactyly、polydactyly、symbrachydactyly、constriction ring）；⑦ 有無症候群（Apert、Poland、Möbius）。 ⭐ 江教授的提醒：「Apert 很少單側！大部分都 bilateral symmetric。」

【⭐ 為什麼前一位醫師沒開完全——high-riding neurovascular bundle】 正常情況下，common digital artery 在大約 web space 或 metacarpal head 的高度分叉成兩條 proper digital artery。在併指的病人，分叉點常常比正常更遠端（distal bifurcation）——分叉點跑到近節指骨的中段甚至更遠，這就是 high-riding neurovascular bundle。 ⭐ 非整形外科的醫師在剝離指蹼時，一看到神經血管束就不敢再往下分，於是就停在那裡。⭐ 江教授的原話：「但我們整外應該知道 neurovascular bundle 走兩側，所以中間是可以繼續分開的。」

【⭐ 遇到 high-riding NV bundle 的四個層次處理】 ① Interfascicular dissection of the nerve——神經幾乎總是可以在束間層次再往近端劈開。 ② ⭐ Ligate 一側的 proper digital artery——先用血管夾暫時夾住、放開止血帶確認另一側動脈足以供應該指之後，才結紮。這是最常用的解法。 ③ 分期手術（staged separation）——先分到安全的高度，等 6 個月以上讓血管適應與再生（arterial arborization）後再做第二階段。 ④ 接受較淺的指蹼——把重點放在功能而非外觀。 ⚠ 絕對禁忌：同一次手術把一根手指「兩側」的指蹼同時分離（尤其多指併指），會造成該指完全缺血。

【手術怎麼開】 ① 先處理已存在的攣縮（如掌側疤痕攣縮 release）；② 探查並處理 high-riding NV bundle；③ ⭐ 指蹼一定要用「皮瓣」重建，不能只靠植皮，否則必然 web creep——標準做法是 dorsal rectangular（Bauer）flap 或 dorsal V-flap／omega flap，把背側皮膚翻下來當指蹼的底；④ 手指側面的 raw surface 用 FTSG 覆蓋（比 STSG 攣縮少，取自腹股溝或肘窩）；⑤ 甲襞融合以小三角瓣重建 paronychial fold；⑥ 術後副木、加壓、長期追蹤到骨骼成熟。

【⭐ 指蹼重建的解剖標準】 正常的指蹼不是一條線，而是一個「斜坡」——從背側往掌側傾斜約 40–45 度，背側緣位於近節指骨的近端三分之一、掌側緣在掌指關節橫紋附近；所以指蹼的正常形態是背側較近端、掌側較遠端。第一指蹼則更寬更深，需要達到拇指可 palmar abduction 至少 45 度以上。

【手術時機】 一般 6 個月至 2 歲；⭐ 但邊緣指蹼（border digits，第 1 與第 4 指蹼）要提早到約 6 個月大——因為相鄰手指長度差異大，不分開會造成 angular deformity 與旋轉變形；中央指蹼可等到 18 個月至 2 歲。⭐ 同一根手指的兩側不可同時手術。」

手指功能百分比與握力、捏力（Percentage of hand function; grip and pinch power）

手外科與周邊神經 · 🟠

一句話定位：全手冊數字衝突最嚴重的兩題——⚠ 必須用「先講出處 → 再涵蓋各版 → 最後回到臨床意義」的三步驟講法。

核心模範答案

「報告老師，這個數字各版本略有出入，所以我分三步講。

【① 先講有公信力的出處】 依 AMA Guides to the Evaluation of Permanent Impairment 的標準：拇指佔手部功能的 40%、食指 20%、中指 20%、環指 10%、小指 10%；而手佔上肢的 90%、上肢佔全人的 60%。

【② 再補一句涵蓋其他版本】 不同教科書與不同勞工保險系統的數字略有出入——有些系統把拇指列到 45–50%，食指與中指各 16–18%、環指與小指各 8–10%；但各版本的「相對關係」是一致的：拇指約佔一半，橈側二指合計約三分之一，尺側二指最少。

【③ 最後回到臨床意義】 所以重建的優先順序是：拇指 → 食指與中指（fine pinch）→ 環指與小指（power grip）。⭐ 但要依病人的職業調整——粗重工作者的 power grip 靠尺側兩指，此時 ulnar digit 的優先度會提高。

【⭐ 正常的 grip / pinch power】 Grip：男性約 30–40 公斤、女性約 20–30 公斤；Key pinch：約 5–7 公斤。 ⚠ 絕對不要講「pinch 大於 grip」——那在生理上不可能（握力動用整隻手的屈肌，捏力只動用拇指與一兩指）。 ⭐ 加分句：日常生活的 functional threshold 大約只需要 grip 20 公斤、pinch 4 公斤，所以重建的目標不是回到正常值，而是達到功能門檻。」

追問樹

  • 考官問「怎麼重建？重建後回到多少？」 → Pollicization（把食指轉位成拇指，同時做出深的第一指蹼）；⭐ 安全講法：「文獻上 pollicization 後可恢復到正常的 50–70%，但更重要的是它把一隻『不能捏東西的手』變成『可以捏東西的手』——這個質變比百分比更有意義。」

米粒體與非典型分枝桿菌感染（Rice bodies; non-tuberculous mycobacterial infection）

手外科與周邊神經 · 🟡

一句話定位：看到「小小白白一顆顆」就要想到培養方式的特殊性——一般細菌培養會是陰性。

核心模範答案

「報告老師，腕部掌側腫痛、術中看到腔室內有『小小白白一顆顆』的組織，這是 rice bodies（米粒體）。

【最典型的病因】 ⭐ 非典型分枝桿菌（non-tuberculous mycobacteria, NTM）的慢性腱鞘滑膜炎。 ⚠ 但不是只有 NTM——類風濕性關節炎（RA）與結核性滑膜炎也會出現 rice bodies。

【組成】 主要是 fibrin 與纖維化組織（由發炎的滑膜脫落、包覆纖維蛋白而成）。

【⭐ 處置——這一段是本題的分數所在】 ① 徹底的 tenosynovectomy（完整清除病態滑膜與 rice bodies）。 ② ⭐ 組織要同時送三種檢查：抗酸菌染色（AFB）、分枝桿菌培養——⚠ 必須「特別交代」低溫 30°C 培養並延長時間到 6 到 8 週——以及病理。因為一般的細菌培養會是陰性，不特別交代就永遠驗不出來。 ③ 確診後需多重抗生素長期治療（常需 6 到 12 個月，例如 clarithromycin ＋ rifampin ＋ ethambutol），並會診感染科。」

追問樹

  • 考官問「只有 NTM 會這樣嗎？」 → ⭐ 不是——類風濕性關節炎與結核性滑膜炎也會。
  • 考官問「病人怎麼得到的？」 → 常見於水族箱、魚刺、園藝、外傷後接觸土壤或水（Mycobacterium marinum 是手部最經典的一株）；免疫低下者風險更高。
  • 考官問「為什麼要低溫培養？」 → M. marinum 等的最適生長溫度約 30–32°C（接近四肢末梢的體表溫度），在標準的 37°C 培養箱長不出來。
