內在肌緊縮與其對照組（Intrinsic tightness; Bunnell–Littler test）

手外科與周邊神經 · 🟠

一句話定位：只講 intrinsic tightness 不夠——一定要同時講出 extrinsic extensor tightness 與 ORL tightness 這兩個對照組，才顯得真的懂。

核心模範答案

「報告老師，intrinsic tightness 是指手內在肌（interossei 與 lumbricals）因為外傷、缺血（compartment syndrome）、燒傷、痙攣、或長期不當固定而攣縮纖維化，導致在 MCP 伸直時 PIP 的被動屈曲受到限制。

【檢查 ＝ Bunnell–Littler test（intrinsic tightness test）】 ① 先把 MCP 固定在伸直（甚至過度伸直）的位置——此時 intrinsic 被拉到最長——測量 PIP 的「被動」屈曲角度。 ② 再把 MCP 屈曲——此時 intrinsic 放鬆——再測一次 PIP 的被動屈曲角度。

【判讀】

  • MCP 伸直時 PIP 難彎、MCP 屈曲時 PIP 可以彎更多 → intrinsic tightness（陽性）。
  • 兩個位置都一樣受限 → 是 PIP 關節本身的關節囊攣縮（capsular contracture），不是 intrinsic 的問題。

【⚠ 兩個對照組——一定要一起講】

  • Extrinsic extensor tightness：MCP「屈曲」時 PIP 的被動屈曲受限、MCP 伸直時反而較好——方向與 intrinsic 完全相反。
  • ORL（oblique retinacular ligament）tightness ＝ Haines–Zancolli test／Boutonnière test：PIP 維持伸直時 DIP 的被動屈曲受限；PIP 屈曲時 DIP 可以彎。

【治療】 早期做 intrinsic stretching（MCP 伸直 ＋ IP 屈曲）與副木；晚期做 distal intrinsic release——切除 extensor expansion 的「斜行纖維（oblique fibers of the lateral band）」，保留 central slip 與 transverse fibers。」

追問樹

  • 考官問「Intrinsic plus 是什麼？跟 intrinsic tightness 有什麼關係？」 → ⭐ 要區分兩件事：「Intrinsic-plus deformity」是病態——intrinsic 攣縮造成的固定變形（MCP 屈曲 ＋ IP 伸直），是 swan-neck deformity 的前身；但「intrinsic-plus position」卻是治療用的安全位副木姿勢，因為它讓 MCP 的 collateral ligament 與 IP 的 volar plate 都處在最長的狀態，可以預防攣縮。⭐ 同一個姿勢，一個是病、一個是藥——這是這題的關鍵。
  • 考官問「安全位副木的四個角度？」 → wrist 20–30° 伸直、MCP 70–90° 屈曲、IP 完全伸直、拇指外展對掌位。⚠ 把手固定在「MCP 伸直、IP 屈曲」的舒服姿勢，兩到三週就會造成永久性攣縮。
  • 考官問「為什麼 intrinsic 攣縮會造成 swan neck？」 → intrinsic 經 lateral band 併入 extensor mechanism，攣縮後把 PIP 拉向過度伸直、同時把力量從 DIP 抽走 → PIP hyperextension ＋ DIP flexion。
