## 一句話定位

**時序表是整關的骨架**，先把它背死；術式部分**兩本課本都明講「沒有唯一首選」**——能講出「無單一共識、主流並存、術者經驗比術式更決定結果」，比背某一種術式的步驟更得分。

## 核心模範答案

### 【一】⭐ 手術時序表（Grabb 9e Ch22, Table 22.1 原表）

| 時間 | 做什麼 |
|---|---|
| 產前 | 影像診斷、多科諮詢 |
| 新生兒 | 醫療與餵食評估、聽力篩檢、遺傳諮詢、治療計畫 |
| **0–3 個月** | **Presurgical orthopedics（PSIO／NAM）** |
| **3–6 個月** | **Primary nasolabial repair ± gingivoperiosteoplasty (GPP)** |
| **9–12 個月** | **Primary cleft palate repair ＋ myringotomy tube** |
| 12–36 個月 | 語言評估與治療 |
| **3–5 歲** | **處理 velopharyngeal insufficiency** |
| **7–10 歲（mixed dentition）** | **Alveolar cleft bone grafting ± palatal expansion**；併處理 secondary nasolabial deformity |
| 青春期 | definitive 或 presurgical orthodontics |
| **骨骼成熟（女約 16、男 18 以上）** | **Le Fort I advancement ± mandibular orthognathic；definitive open rhinoplasty** |

⭐ **順序陷阱**：**正顎要先做、鼻整形後做**——因為 Le Fort I 會前移 ANS、把鼻尖推出去並撐寬 alar base〔Grabb 9e Ch22〕。

⚠ **rule of 10s（10 週、10 磅、Hb 10）課本查無明確出處**——Grabb Ch22 與 Neligan Vol3 Ch19.1–19.4、Ch21.1–21.3、Ch21.7 都不用它。**主答月齡區間，rule of 10s 只當歷史補充。**

**唇裂修補：3–6 個月**（兩本一致）。寬的 complete cleft 且無法做 PSIO 時可分兩階段：**先 nasolabial adhesion，約 3 個月後再正式修補**〔Grabb 9e Ch22〕。雙側唇裂同樣 3–6 個月，且**通常一次做完以求對稱**；premaxilla 突出者先以 PSIO 或 premaxillary setback 處理。

**顎裂修補的月齡——課本用的是「6–12 個月」這一派，不是 9–18**：

| 出處 | 說法 |
|---|---|
| 〔Grabb 9e Ch22〕 | **多數術者在 9–12 個月同時修 hard 與 soft palate**；**超過 12 個月**才修，孩子會發展出 maladaptive errors |
| 〔Neligan Vol3 Ch21.1〕 | 「typically performed **around 12 months**」 |
| 〔Neligan Vol3 Ch21.3〕 | 多數同意健康病人最佳時機**約 10–12 個月**；Shaffer 顯示**超過 13 個月**語言結果較差 |
| 〔Neligan Vol3 Ch21.2〕 | Sommerlad 本人偏好 **6 個月**；有良好證據顯示**延後超過 12 個月對語言有害** |

⭐ **共識底線：12 個月前完成。** 延後的例外（兩本一致）：體重增加不佳、心臟異常、氣道未優化；**Robin sequence 要更謹慎、可稍延後**以免術後氣道阻塞〔Grabb 9e Ch22；Neligan Vol3 Ch21.2, 21.3〕。

**齒槽骨移植——兩本判準不同，要並列**：

- 〔Grabb 9e Ch22〕**Boyne–Sands protocol 仍是 standard of care**：X 光上**犬齒牙根形成「一半」**時植入 cancellous bone；表列時機 **7–10 歲 mixed dentition**；取骨自髂骨嵴。移植前先做 palatal expansion 可改善視野與鼻底閉合。
- 〔Neligan Vol3 Ch21.7〕分兩段：**Early secondary 4–7 歲**（lateral incisor 萌出前，鄰牙萌入移植骨提供功能性負載，骨形成較好、吸收較少）；**Late secondary 8–12 歲**（permanent canine 萌出前）。cleft 側有 **50%–70%** 先天缺 lateral incisor。
- ⚠ **「犬齒牙根形成 2/3」兩本皆查無出處。**

### 【二】分類：Veau 是兩本共同的主力

〔Grabb 9e Ch22〕「CP **is most frequently characterized using the Veau classification**」；〔Neligan Vol3 Ch21.1〕「**The Veau classification is often used**」。全書行文也用 Veau 標記病例。

| 型 | 定義〔Neligan Vol3 Ch21.1〕 |
|---|---|
| **Veau I** | **只有 soft palate** |
| **Veau II** | secondary palate 完全裂，含 soft ＋ hard palate，**向前延伸到 incisive foramen 為止**（不含齒槽） |
| **Veau III** | **單側**完全裂，含 primary ＋ secondary palate；**vomer 附著在非裂側上顎骨** |
| **Veau IV** | **雙側**完全裂；**premaxilla 突出、vomer 位在正中線** |

**其他工具（Grabb 有寫，是文件記錄用，不是主推）**：
- **Kernahan striped-Y**：lip(1、4)、alveolus(2、5)、incisive foramen 前 hard palate(3、6)、其後 hard palate(7)、soft palate(8)、uvula(9)。
- **LAHSHAL**：Lip(右)–Alveolus(右)–Hard palate(右)–Soft palate–Hard palate(左)–Alveolus(左)–Lip(左)。**大寫＝complete、小寫＝incomplete、星號＝minor form、點＝正常。**
- **唇裂形態譜**〔Grabb Fig 22.5〕：complete／incomplete／**minor form**（Cupid's bow peak 抬高 3–5 mm）／**microform**（抬高 <3 mm）／**mini-microform**（僅 vermilion-cutaneous junction 有 notch）。

**流行病學（可一起背）**〔Grabb 9e Ch22〕：CL/P 男：女＝**2:1**，isolated CP 女多（2:1）；**左：右：雙側＝6:3:1**；CL 約 **15%** 為 syndromic，**isolated CP 高達 50%** 為 syndromic。

### 【三】唇裂修補術式——⭐「沒有共識」本身就是標準答案

〔Grabb 9e Ch22〕原句：「While the universal goal is symmetry, **there is no consensus about the ideal repair technique. Various protocols can yield comparable outcomes in experienced hands.**」並補「**Variations of the Millard repair continue to be widely used.**」

〔Neligan 5e〕的編排即態度——三種術式**各給獨立一章、各由代表人物執筆、並列不排名**：Ch19.2 Rotation advancement（陳國鼎／長庚）、Ch19.3 Extended Mohler（Flores）、Ch19.4 Anatomic subunit（Tse ＋ Fisher 本人）。

| 術式 | 原理 | 缺點 |
|---|---|---|
| **Millard rotation-advancement**（1955／57） | 內側唇以**不侵犯非裂側 philtral ridge** 的 **back-cut** 向下旋轉；外側 advancement flap 填缺損，Z-plasty 置於 nasal sill 下方；**C-flap 關 nasal floor** | ① **上 1/3 違反 subunit 界線**；② 用外側唇填 back-cut → 寬裂時 alar base 過度內移造成 **micronostril（無確定矯正法）**；③ perialar incision 可防但該處**疤痕癒合差** |
| **Mohler／Extended Mohler（Cutting）** | **把 back-cut 從上唇移到 columella**，缺損由 **C-flap 向上旋轉**填補 → **philtral subunit 完整重建、疤痕正落在 subunit 界線** | 學習曲線在頂點與基部的微調：頂點太低→旋轉不足；太偏裂側→**C-flap 太窄（即「columella 過窄」批評的來源）** |
| **Fisher anatomic subunit**（2005） | rotation-advancement 與 Randall inferior triangle 的混血，**完全不切到 columella**；直線設計＋外側預量的 **inferior triangular flap**；**所有標記點皆為解剖決定** | 乍看像切除過多裂緣組織，但實際是內外側**較平均分攤** |

⭐ **Extended Mohler 的加分點**：C-flap 上移**同時把下陷的 medial crura 上提、延長 columella**；外側唇內移量少 → **micronostril 風險降低**，通常只要 alar base 短橫切口；back-cut 頂點在 columella，**提供 medial approach 做 primary rhinoplasty 的絕佳入路**。

⭐ **長庚陳國鼎的判準**〔Neligan Vol3 Ch19.2〕：以 SN 到兩側 Cupid's bow peak 的高度差決定——**差 >2 mm 用 Mohler's incision；差 <2 mm 用 simple rotation incision**；**columella 過窄者應避免 Mohler 切口**。（⭐ 林政輝是長庚體系，這一條值得主動講。）

⭐ **Fisher 的核心邏輯**：垂直高度靠 **Rose–Thompson effect** 取得，故 inferior triangle 很小；**外側閉合點固定在 Noordhoff's point**，垂直高度不足時以調整外側標記各段夾角吸收，**絕不為了拿垂直高度而犧牲外側唇的橫向寬度**（rotation-advancement 會把閉合點外移超過 Noordhoff point，代價是紅唇變薄、像手風琴一樣捲進嘴裡）。

**不論用哪一種，兩本共同強調兩件事**：
1. **肌肉重建優先於皮膚切口設計**——「Regardless of skin incision pattern, **muscular alignment is necessary to reconstitute the oral sphincter**」。內側 orbicularis 鬆解但**限制皮下剝離以保留 philtral dimple**；外側可較徹底游離。
2. **Primary rhinoplasty 已是標準配備**——centralize caudal septum、修 nasal floor 與側壁、擺正 alar base；多數術者加做 tip rhinoplasty 並**略微過度矯正**。**輕微鼻尖變形偏好 closed 入路**，以減少疤痕干擾日後正式鼻重建。

### 【四】顎裂修補術式——先講 Grabb 的分類骨架

〔Grabb 9e Ch22〕把顎裂修補**拆成 hard palate 與 soft palate 兩組**，因為兩者可自由組合：

- **Hard palate**（都靠 greater palatine vessels 的黏骨膜瓣）：von Langenbeck／Veau–Wardill–Kilner V–Y pushback／Bardach two-flap；鼻側襯裡用 vomer flap。
- **Soft palate**（現代準則＝**velar 肌肉的重新定位與對合**）：兩大主流只差在「肌肉是否環周剝離＋直線縫合」vs「肌肉留在一面黏膜上、用 Z-plasty 延長軟顎」→ **IVVP vs Furlow**。

⭐ **Grabb 的裁決句（很好背）**：「Although proponents of each technique tend to be strong advocates, **data reported by the highest-volume centers demonstrate both techniques have good outcomes**… **regardless of the type of soft palate repair used, good muscular reorientation and approximation are most important.**」

| 術式 | 定位（課本原句） | 要點 |
|---|---|---|
| **Bardach two-flap** | 〔Grabb〕「**The most versatile**」——最泛用、能關最寬的裂 | 血管蒂可游離成 island flap ＋ **infracture hamulus** ＋ 廣泛外側剝離；代價是兩外側 donor site 二次癒合、與生長受限有關 |
| **von Langenbeck** | 〔Grabb〕「**most useful for narrow hard palatal clefts**」 | 齒槽脊內側 relaxing incision，黏骨膜掀成 **bipedicled flaps**；Sommerlad 只做有限度切口，**約 10% 病人需要** |
| **V–Y pushback (Veau–Wardill–Kilner)** | 〔Grabb〕「**has largely fallen out of favor**」 | 大面積前方 donor site 影響上顎生長；〔Neligan Ch21.1〕**greater palatine 神經血管束的 tethering 使 V–Y 在懸壅垂處幾乎沒有實際延長效果** |
| **IVVP／Sommerlad straight-line** | 〔Grabb〕「achievable **even in very wide clefts**」——**寬裂也做得到**，正好補 Furlow 的弱點 | 把 levator veli palatini 與 palatopharyngeus **環周剝離**後向後內側旋轉 |
| **Furlow double-opposing Z-plasty** | velar repair，**可與任何一種 hard palate 術式搭配**〔Neligan Ch21.3〕 | 雙對向 Z-plasty ＋ 重建 **LVP sling** → 延長軟顎、防攣縮、優化 VP 功能 |

⭐ **Furlow 的適應症（Neligan Ch21.3 明列三項）**：① primary cleft palate repair；② **矯正既有 VPD 的 secondary／conversion Furlow**，特別適用 nasoendoscopy 顯示 **VP gap < 5 mm** 者；③ **合併 VPD 的 submucous cleft palate**。

⭐ **Furlow 的缺點（常考的反面）**：〔Grabb〕「**lengthens at the expense of palatal width, making closure of wide clefts challenging**」，可能需 buccal fat pad／buccal myomucosal flap 覆蓋。〔Neligan Ch21.3〕另列：非解剖性、可能不對稱、寬裂困難、**日後難以修正**。

**Relaxing incision 的爭議**：Furlow 原版強調**避免**（怕影響上顎生長）；**Randall／CHOP modification 主張需要時就用**，且 **CHOP 長期追蹤顯示並未影響上顎生長、咬合或正顎手術需求**〔Neligan Ch21.3〕。

**成績數據（可背）**〔Neligan Ch21.3〕：CHOP 261 名 non-syndromic → **VP 功能不全 6%、二次手術 6.5%、顎瘻管 6.8%**；2019 meta-analysis 顯示 Furlow **瘻管較少且 VP 結果較好**；但 2011 RCT（Furlow vs von Langenbeck＋IVVP）顯示 **Furlow 語言較好、但瘻管率較高**，且**瘻管只發生在未用 relaxing incision 的寬裂**。

⭐ **顎裂 levator 的三個異常附著（很好考）**〔Neligan Ch21.1〕：① **裂側 hard palate 的後內側緣**；② **tensor veli palatini 的 aponeurosis**；③ **與 superior constrictor 的外側沾黏**。**初次 palatoplasty 必須把這三處鬆開。**

⭐ **軟顎的功能分區**〔Neligan Ch21.1／21.3〕：前 **25%** 相對靜態（tensor veli palatini／aponeurosis）；**中間 50% 是 LVP sling，為軟顎主要動力**；後 25% 為 palatoglossus、palatopharyngeus、musculus uvulae。**LVP 收縮使軟顎向上、向後、向外**牽引以完成 velopharyngeal closure。

**現代的組織增補**〔Grabb Ch22；Neligan Ch21.1〕：**buccal fat** 填 relaxing incision、或填 hard–soft palate 交界（**瘻管風險最高處**）的死腔；**buccal myomucosal flap**（random-pattern，與 FAMM flap 不同）用於關 hard palate、補強極寬裂、延長過短軟顎。⭐**雙側 buccal myomucosal flap 做二次顎延長，對許多顎裂醫師而言已大致取代 pharyngoplasty。**

### 【五】併發症數字——⚠ 這一格坊間流傳的數字都不對

| 項目 | 課本數字 |
|---|---|
| **Oronasal fistula** | **meta-analysis 匯總 4.9%**〔Neligan Ch21.1，Bykowski/Losee 2015〕；文獻全距 **<1%–76%**〔Neligan Ch21.6〕。最常在 **hard–soft palate junction（Pittsburgh Type III）**；**Veau IV 風險最高**；多在**術後 6 個月內**出現 |
| **Palatoplasty 後發生 VPI** | **5%–25%**〔Grabb 9e Ch32，全章寫三次〕；註明是**高資源環境**的數字 |
| **真正臨床需要 VPD 二次手術** | **8%**（Furlow 系列追蹤到 5 歲）〔Neligan Ch21.9〕 |
| **VPI 手術後仍需再手術** | 合計 **8%–9%**；palatal lengthening 5–10%、posterior pharyngeal flap 3.5–6%、sphincter pharyngoplasty 8.2–10.6%〔Grabb Ch32〕 |
| 圍手術期 adverse airway events | **總計 23%**（hypoventilation 10%、阻塞 8%、reintubation 5%、喉支氣管痙攣 3%）；危險因子含**手術 >160 分鐘**、**narcotic >0.3 mg/kg**〔Neligan Ch21.1〕 |
| Otitis media with effusion | **96%–100%**，故 palatoplasty 同時放 myringotomy tube〔Neligan Ch21.1〕 |

⚠ **常見錯誤**：把瘻管講成 5–10%（課本是 **4.9%**）、把需二次手術講成 20–30%（課本是 **8%**，VPI 發生率才是 5–25%）。

### 【六】胚胎學

〔Grabb 9e Ch23〕**facial morphogenesis 第 4–8 週**（Carnegie stage 10–21）；〔Neligan Vol3 Ch18〕**顏面基本形態於第 4–10 週建立**。上唇由 **maxillary ＋ medial nasal prominence** 融合，nasal swellings 於**第 4 週末**形成。

**顎**〔Neligan Ch21.1〕：「begins to form during the **5th week** and is not completed until the **12th week**」，最關鍵期 **第 6–9 週**。〔Grabb Ch23〕primary palate 第 5 週、secondary palate 第 6 週起、**第 8 週 shelves 上抬並中線融合**。

⭐ **胚胎學角度的顏面裂分類（口試很好用）**〔Neligan Ch18〕：frontonasal 與 maxillary 未融合 → **cleft lip**；lateral nasal 與 maxillary 未融合 → **oblique facial cleft**；frontonasal 與 lateral nasal 未融合 → **alar cleft**；maxillary 與 mandibular 未融合 → **transverse facial cleft**。

⭐ **中斷時間點與嚴重度**：「the **earlier** in development the process is disrupted, the **more severe (complete)** is the palatal cleft.」

## 追問樹

| 考官問 | 你答 |
|---|---|
| 「什麼時候開刀？」 | ⭐ 直接把 Table 22.1 倒出來：0–3 月 PSIO → **3–6 月唇** → **9–12 月顎＋耳管** → 3–5 歲 VPI → **7–10 歲齒槽骨移植** → 骨骼成熟後正顎、最後鼻整形 |
| 「為什麼顎裂要在一歲前修？」 | 超過 12 個月孩子會發展出 **maladaptive articulation errors**；Shaffer 顯示 >13 個月語言結果較差〔Grabb Ch22；Neligan Ch21.3〕 |
| 「rule of 10s？」 | ⚠ **兩本課本都沒有寫**。主答 **3–6 個月**，rule of 10s 只當歷史補充 |
| 「正顎跟鼻整形哪個先？」 | ⭐ **正顎先**——Le Fort I 會前移 ANS、撐寬 alar base，鼻整形要在其後〔Grabb Ch22〕 |
| 「Veau 分幾型？」 | 四型；⭐ 關鍵是 **II 型止於 incisive foramen**、**III 單側 IV 雙側** |
| 「唇裂你用哪一種術式？」 | ⭐ 先講「**課本明講沒有共識，術者經驗比術式更決定結果**」，再講三種主流的解剖邏輯與各自缺點 |
| 「Millard 的缺點？」 | ① 上 1/3 違反 subunit 界線 ② 寬裂時 alar base 過度內移造成 **micronostril，且無確定矯正法** ③ perialar incision 疤痕癒合差 |
| 「Mohler 好在哪？被批評什麼？」 | 好在 back-cut 移到 columella → **philtral subunit 完整、疤痕落在界線上**，且是 primary rhinoplasty 的好入路；被批評 **columella 過窄**——那是頂點太偏裂側造成 C-flap 太窄 |
| 「Fisher 的核心是什麼？」 | **measure-twice-cut-once**：所有標記點解剖決定；**外側閉合點固定在 Noordhoff's point**，絕不犧牲外側唇橫向寬度換垂直高度 |
| 「Furlow 什麼時候用？」 | ⭐ 三個適應症：primary repair、**VP gap < 5 mm 的 conversion Furlow**、**合併 VPD 的 submucous cleft** |
| 「Furlow 的缺點？」 | ⭐ **以顎的寬度換長度**，寬裂難關；另有非解剖性、可能不對稱、**日後難修正** |
| 「寬裂你會選什麼？」 | **Bardach two-flap**（最泛用、能關最寬）＋ **IVVP**（寬裂也做得到）；Furlow 在寬裂反而吃虧 |
| 「levator 有哪些異常附著？」 | ⭐ 三處：裂側 hard palate 後內側緣、tensor 的 aponeurosis、與 superior constrictor 的外側沾黏 |
| 「瘻管率多少？」 | **4.9%**（meta-analysis）；文獻全距 <1%–76%；最常在 **hard–soft palate junction**、**Veau IV 風險最高** |
| 「多少人會 VPI？多少要再開刀？」 | ⭐ 分清母數：**VPI 發生 5–25%**〔Grabb Ch32〕；**真正需二次手術 8%**〔Neligan Ch21.9〕 |
| 「顎裂為什麼要放中耳通氣管？」 | **OME 發生率 96–100%**，故 palatoplasty 同時放〔Neligan Ch21.1〕。⚠ 但 Sommerlad 主張 radical muscle repair 可改善耳咽管功能、**他不同時放管**〔Neligan Ch21.2〕 |
| 「胚胎學上什麼時候出問題？」 | 唇 **4–8 週**；顎 **5–12 週**、關鍵期 6–9 週；⭐ **越早中斷、裂越完全** |

## ⚠ 衝突與裁決

| 爭點 | 版本 A | 版本 B | 裁決 |
|---|---|---|---|
| **顎裂修補月齡** | 〔Grabb〕多數 **9–12 個月**同時修 hard＋soft | 〔Neligan Ch21.2〕Sommerlad 本人 **6 個月**（vomer flap 分兩階段） | ⭐ 主答 **9–12 個月**，共識底線是**12 個月前**；被引 Sommerlad 就順著講他的兩階段協定 |
| **齒槽骨移植的判準** | 〔Grabb〕**犬齒牙根形成一半**，7–10 歲 | 〔Neligan Ch21.7〕**early 4–7 歲**（lateral incisor 萌出前）／**late 8–12 歲**（canine 萌出前） | 兩個都講；⚠ **「2/3」兩本皆查無，不要報** |
